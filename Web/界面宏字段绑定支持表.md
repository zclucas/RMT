# 界面宏字段绑定支持表

自定义界面宏的浮窗控件可以绑定到某条宏、某一步的一个参数。在浮窗里修改控件，会改这个参数的当前值；使用界面上的「写入宏」后，才保存到宏文本或指令数据。不写入就关闭浮窗时，参数回到打开前的值。

宏类型下拉列出当前配置里的可用宏，不限于界面宏本身。下面按控件类型和指令列出目前可以绑定的字段。未列入的指令不会出现在挑选器中。

## 1. 控件与值类型

| 值类型 / 目标 | 可用控件 | 校验与行为 |
|---|---|---|
| 整数（`int`） | 输入框 | 只接受整数，并校验字段规定的范围 |
| 文本（`text`） | 输入框 | 最长 500 字；默认拒绝宏分隔符和 `_`，明确允许分隔符的字段除外 |
| 枚举（`enum`） | 下拉框 | 只能选择预设值；当前字段白名单中有 RMT 指令 |
| 布尔（`bool`） | 勾选框 | 当前用于步骤的「是否执行」开关 |
| 任意字段 | 只读文本 | 仅显示值，不写回字段 |
| 触发宏（操作项） | 按钮 | 绑定所选宏本身，不绑定某一步的参数 |

只读文本可用于显示已支持的字段。字段值类型与其对应的可编辑控件不能互换。

## 2. 内联参数

内联参数直接写在宏步骤文本中。只列出步骤中实际存在、且允许绑定的参数，不会自动补齐缺少的参数。

| 指令 | 参数 | 类型 / 范围 | 说明 |
|---|---|---|---|
| 间隔 | 第 2 段：时长 | 整数 `0–3600000` | 当前值为纯整数时按整数校验 |
| 间隔 | 第 2 段：时长~上限 | 文本 | `N~M` 整段作为文本处理 |
| 按键 | 第 2 段：键名 | 文本 | 已登记的特殊键名允许包含 `_` |
| 按键 | 第 4 段：点击时长 | 整数 `0–60000` | 当前值不是纯整数时按文本处理 |
| 按键 | 第 5 段：点击次数 | 整数 `1–9999` | 当前值不是纯整数时按文本处理 |
| 按键 | 第 6 段：每次间隔 | 整数 `0–60000` | 当前值不是纯整数时按文本处理 |
| 其他内联步骤 | 第 2 段起的实际参数 | 文本 | 标签显示为「第 N 段」 |

按键的第 3 段「动作」以及间隔 / 按键中作为备注的第 3 段不开放绑定。内联文本默认不能输入 `_`、逗号、中文逗号、换行或 `⫶`，以免破坏步骤和参数结构。

## 3. 序列指令字段

序列指令的字段保存在对应指令数据对象中。文本字段的长度上限均为 500 字；“允许分隔符”表示该字段可包含宏分隔符及 `_`。

| 指令类型 | 字段（存储路径） | 类型 / 范围 | 候选控件 | 条件与备注 |
|---|---|---|---|---|
| 变量 | 赋值内容（`VariableArr.1`） | 文本 | 输入框 | 仅开放第 1 个变量槽 |
| 变量 | 随机下限（`MinVariableArr.1`） | 整数 `0–999999999` | 输入框 |  |
| 变量 | 随机上限（`MaxVariableArr.1`） | 整数 `0–999999999` | 输入框 |  |
| 循环 | 循环次数（`LoopCount`） | 整数 `-1–999999` | 输入框 | `-1` 表示无限循环 |
| 运行 | 目标（`Target`） | 文本 | 输入框 |  |
| 等待 | 检测间隔（`Interval`） | 整数 `0–60000` | 输入框 |  |
| 等待 | 主参数（`Param1`） | 文本 | 输入框 | 含义随等待模式而异 |
| 搜索 / 搜索Pro / 搜索Combo / 组合搜索 / 搜索Multi | 相似度（`Similar`） | 整数 `50–100` | 输入框 | 仅图片搜索类型 |
| 搜索 / 搜索Pro / 搜索Combo / 组合搜索 / 搜索Multi | 检索文本（`SearchText`） | 文本 | 输入框 | 仅文本搜索类型；允许分隔符 |
| 搜索 / 搜索Pro / 搜索Combo / 组合搜索 / 搜索Multi | 搜索次数（`SearchCount`） | 整数 `-1–9999` | 输入框 | `-1` 表示无限 |
| 搜索 / 搜索Pro / 搜索Combo / 组合搜索 / 搜索Multi | 搜索间隔（`SearchInterval`） | 整数 `0–60000` | 输入框 |  |
| 输出 | 输出内容（`Text`） | 文本 | 输入框 | 允许分隔符 |
| 鼠标移动 / 移动 | 目标 X（`PosX`） | 整数 `0–65535` | 输入框 |  |
| 鼠标移动 / 移动 | 目标 Y（`PosY`） | 整数 `0–65535` | 输入框 |  |
| 鼠标移动 / 移动 | 移动速度（`Speed`） | 整数 `0–100` | 输入框 |  |
| 增量移动 | 横向位移（`DeltaX`） | 文本 | 输入框 | 支持 `{变量}`；允许分隔符 |
| 增量移动 | 纵向位移（`DeltaY`） | 文本 | 输入框 | 支持 `{变量}`；允许分隔符 |
| 增量移动 | 偏移次数（`Count`） | 文本 | 输入框 | 支持 `{变量}`；允许分隔符 |
| 增量移动 | 每次间隔（`Interval`） | 文本 | 输入框 | 支持 `{变量}`；允许分隔符 |
| 倒计时 | 秒数（`Seconds`） | 整数 `1–86400` | 输入框 |  |
| RMT 指令 | 指令（`CmdStr`） | 枚举，共 27 项 | 下拉框 | 预设值与 RMT 指令编辑器一致 |
| RMT 指令 | 菜单序号（`MenuIndex`） | 整数 `1–99` | 输入框 | 仅「显示菜单」时有执行意义 |

搜索字段按数据对象的 `SearchType` 过滤：相似度仅用于图片搜索，检索文本仅用于文本搜索；搜索次数和搜索间隔始终可选。旧数据对象没有 `SearchType` 时，为避免误隐藏字段，挑选器会保留这些候选项。

## 4. 宏操作项与步骤开关

| 项目 | 控件 | 行为 |
|---|---|---|
| 触发宏 | 按钮 | 在挑选器中选择「触发宏」，生成的按钮运行当前选定宏；它不是宏字段 |
| 是否执行 | 勾选框或只读文本 | 勾选表示执行；取消勾选会在步骤文本前添加 `🚫`，与主界面的跳过指令机制一致 |

步骤开关适用于顶层步骤和下方列出的嵌套容器内的步骤。

## 5. 嵌套宏容器

以下容器可在挑选器中展开。容器里的步骤使用相同字段白名单，绑定会保存完整嵌套路径。

| 指令 | 可展开内容 |
|---|---|
| 如果 | 真分支、假分支 |
| 如果Pro | 分支 1 至 N、默认分支 |
| 循环 | 循环体 |
| 搜索 / 搜索Pro / 搜索Combo / 组合搜索 / 搜索Multi | 真分支、假分支 |

嵌套最多 5 层。步骤或容器被修改、删除后，原绑定路径可能失效；失效路径会报出提示，不应继续写入旧位置。宏操作引用子宏的方式不稳定，因此不会递归展开其目标宏。

## 6. 暂不支持的字段

下列指令或数据目前不在字段白名单中。它们不会因为在数据对象中存在属性就自动出现在挑选器里。

| 指令 / 字段 | 暂不支持的原因 |
|---|---|
| 时间 | `SubMode` 对应多种模式，同名字段语义不同 |
| 注释 | 不参与执行，绑定只会改变显示文字 |
| 如果 / 如果Pro 的条件字段 | 比较类型和变量值具有模式及数组索引语义；分支容器本身仍可展开 |
| 运算 / 文本处理 / 数组 / 文件读写 | 字段与操作模式、数组结构相关，尚无逐字段规格 |
| 抓图 / 图形节点 / 图形开始节点 | 使用路径对象或节点数组，单字段写入不足以表达完整配置 |
| 窗口管理 | 参数与移动、调整大小、关闭等动作类型耦合 |
| 后台鼠标 / 后台按键 / Timing / 按键检测 / 手柄检测 | 数据结构和写入语义尚未纳入白名单 |
| 宏操作的目标字段 | 目标以宏类型和序号引用，宏增删后可能错位 |
| 搜索内的多点找图采样数据 | 属于数组数据，单字段编辑可能破坏采样结构 |

## 7. 写入与占用

- 控件修改先更新运行时内存；使用界面提供的宏写入操作后，才保存到宏文本或指令数据文件。
- 整数越界或格式不合法时会拒绝写入；文本字段受长度和分隔符规则约束。
- 挑选器按宏类型和宏分别定位来源；绑定身份使用宏 ID、步骤 / 字段及必要的嵌套路径。
- 其他面板已绑定的候选项会标记为占用；同一面板内允许重复绑定，例如同时使用输入框和只读文本。
