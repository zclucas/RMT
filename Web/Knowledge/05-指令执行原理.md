# 指令执行原理

源：`Main/Util/MacroUtil.ahk` 的 `ExecuteMacroCmdOnce` 及各 `On*`。  
参数说明以 `Web/指令手册.md` 为准，本文补「运行时到底怎么走」。

---

## 1. 宏字符串怎么拆

`SplitMacro` 分隔符：`,` `，` 换行 `⫶`  
空段丢掉。

前缀：

- `🚫` 整条跳过
- `⭐` 调试标记，执行仍走原指令

`GetCmdStr` 会去掉这两种符号再解析。

指令名 = 第一段去掉末尾数字。所以 `搜索3`、`循环12` 都识别成对应类型，数字是序列号。

---

## 2. 两类指令

### 2.1 参数写在字符串里（无独立 ini）

| 指令 | 格式 | 执行函数 |
|------|------|----------|
| 间隔 | `间隔_毫秒` 或 `间隔_A~B` | `OnInterval` |
| 按键 | `按键_键名_按下\|松开\|点击[_时长_次数_间隔]` | `OnPressKey` |
| 移动 | `移动_X_Y_速度_方式` | `OnMouseMove` |
| RMT指令 | `RMT指令_类别_指令`（显示菜单再加 `_序号`） | `OnRMTCMD` |

### 2.2 第一段是序列号，参数在 JSON

`GetMacroCMDData(序列号)` → 读对应 `*File.ini` → 缓存。  
搜不到序列号会 new 一个默认对象（看起来像「指令在，但参数是默认值」）。  
**注释、抓图、后台鼠标/按键、窗口管理、按键检测、手柄检测**都属于这一类，不要当成行内参数指令。

---

## 3. 逐条说明

### 间隔

- 单值：可变量。随机：`时间1~时间2`。
- 再套 `IntervalFloat`。
- `InterruptibleSleep`：暂停/终止能打断。
- 放在宏末尾 = 每轮循环之间的间隔。

### 按键

1. `SplitCommand` 处理 `Launch_App2` 这类带下划线的键名。
2. 手柄通用名转友好名（`Joy1`→`JoyA` 等）。
3. 按 `ModeArr` 选发送：1 SendNormalKey / 2 SendGameModeKey / 3 SendLogicKey / 4 SendAHIKey。
4. 手柄键走 ViGEm：按钮 / 轴 / 十字键。
5. 类型：按下、松开瞬发；点击耗时 `(时长+间隔)*次数 - 间隔`。
6. 时长再套 `HoldFloat`，间隔套 `PreIntervalFloat`。
7. 「按下时按下」见设置文档。
8. 按下的键记入 `HoldKeyArr`，仅终止或开关结束时统一松开。

要点：按下不是系统自动连发；不松再按可能卡键；点击 <200ms 像单击，>250ms 像长按。

### 搜索 / 搜索Pro

`SearchOnTrigger`：

- 按次数搜。无限次数：一直等到找到，假分支不会走。
- 找到：可选移动/点击，同时把 `TrueMacro` 插进后续指令。
- 没找到且还有次数：`ExecuteMacroCmdOnce` **把本条再插回下一条**（忙等重试）。
- 次数用尽：走 `FalseMacro`。
- 可写结果变量、坐标变量。

搜索 ≠ 开放识别，素材要和屏幕几乎一致。范围小、图小（32×32 / 48×48）更快。  
OpenCV：默认灰度匹配；搜索 Pro、搜索 Combo 的图片目标可单独勾选「颜色匹配」，不再由 95% 相似度切换。RMT ImageSearch 不显示该选项。
窗口搜索可对多个匹配窗口做鼠标动作。

### 移动 / 移动Pro

**移动**（参数写在串里，无 ini）：

- 格式：`移动_X_Y_速度_方式`。方式：`0` 绝对，`1` 相对，`2` 游戏视角。省略则绝对、速度 `90`。
- 坐标只能是整数，套 `CoordXFloat` / `CoordYFloat`。
- 实际怎么移动，跟随该条宏 `ModeArr`（AHK / 罗技 / AHI）。
- 不能填变量、不能顺便点击。

**移动Pro**（`MMProFile.ini`）：

- `MouseMoveMode`：`0` 绝对 `1` 相对。旧值 `2` 游戏视角已拆为「增量移动」指令，旧配置仍按 mouse_event 相对位移兼容执行，也只有方式=2 时才保留 `Count` / `Interval`。
- `ActionType`：1 移动 / 2 移动后单击 / 3 移动后双击 / 4 拖拽。拖拽绝对时「起始点按下 → 移到终止点（EndPosVarX/Y）松开」，相对时按 `PosVarX/Y` 偏移拖动；按下后必定松开。
- `RefMode` / `WinInfo`：坐标基准为窗口且绝对移动时，起止点都按窗口左上角偏移；找不到窗口则不执行。
- `IsHumanMouse`：拟真轨迹（类默认没有此字段，旧数据可能缺，按 0）。开启后界面把 `ActionType` 固定为「移动」，罗技 / AHI 下按普通轨迹走。
- 坐标可变量；取不到则本条不移动，且套 `CoordXFloat` / `CoordYFloat`。

### 输入

支持弹窗、真假按钮、单选、多选和选择文件。Worker 将请求交给主进程，等待结果后再继续。选择文件成功时写入完整路径，取消时保留结果变量。配置超时后按选定动作处理。

### 等待 / 倒计时

等待变化类条件时，先在运行态保存基准，再按检测间隔轮询。等待确定由主进程显示交互窗口。设置了状态变量时，完成和超时分别写入对应状态值。独立的倒计时指令通过主进程显示 XAML 浮层。

### 输出

`{var}` 或 `{εArr}` 替换后，按类型输出到目标程序、指令窗口、弹窗、语音或剪贴板。临时提示由主进程显示，并跟随鼠标。

### 循环

按 `LoopCount` 跑 `LoopBody`。  
继续条件：条件不成立则本轮不跑体。  
退出条件：条件成立则离开循环。  
条件数量不限，且/或，比较方式和「如果」相同。  
体内「如果」的流程控制可跳过本轮或跳出。  
内层 `循环次数` 变量表示当前是第几轮。

### 宏操作

| CallType | 行为 |
|----------|------|
| 插入到当前宏 | 把目标 `MacroArr` 重复 `InsertCount` 次，作为返回值插入当前流（并行不增加） |
| 触发 | `MyTriggerSubMacro`，另一条宏同时跑 |
| 暂停 / 取消暂停 / 终止 | 改目标宏状态 |

目标按 `MacroType` 和 `MacroSerial` 定位，`Index` 仅记录配置时的显示序号。

`当前宏` 指正在执行的这一条。子宏页签自己没有热键。

### 变量

最多 4 路。类型以代码为准：1 数值 2 随机 3 字符 4 系统 5 删除。  
`IsIgnoreExist` 为真且变量已在则跳过。系统变量只读。

### 变量提取

OCR/剪贴板/窗口文本，按 `&x` `&c` 模板写入最多 6 个变量。  
失败：新变量=0，旧变量不动。也可按次数重试（返回重插本条）。

### 如果 / 如果Pro

如果：任意数量条件，且/或，真假双分支 + 流程控制 + 可选保存真/假值。  
如果Pro：多分支自上而下，都假走默认。  
比较：> >= == != <= < 包含 变量存在 正则。

### 运算

表达式求值写入结果变量，源变量不变。

### 运行 / 运行Pro

**运行**：固定 Mode=1、Option=1，只填目标。  
**运行Pro**：1 直接 Run；2 RunWait 存退出码；3/4 管道 stdin，4 还可存 stdout/stderr。窗口选项：隐藏/普通/最小化/最大化。  
路径支持变量替换。旧「运行」若带 Pro 字段，编辑时仍打开运行Pro，序列号不变。

### 文件读写 / 文本处理 / 数组

见指令手册。数组下标从 1，`MainIndex=0` 表示整个数组。

### RMT指令

`RMT指令_类别_指令`。显示菜单：`RMT指令_宏控制_显示菜单_序号`。

| 类别 | 指令 |
|------|------|
| 图文 | 截图、截图提取文本、自由贴 |
| 输入控制 | 启用/禁用 鼠标、键盘、键鼠、鼠标加速（需管理员） |
| 宏控制 | 显示菜单、关闭菜单、暂停/恢复/终止所有宏 |
| 调试 | 开启/关闭变量监视、开启/关闭指令显示 |
| 软件自身 | 休眠、重载、关闭软件 |

输入控制走 `ApplyRmtInputControl`，不再当普通 RMT 动作广播。  
「截图」走设置里的 `ScreenShotType`（微软 / RMT / SC），**不是**「抓图」指令。

### 后台鼠标 / 后台按键

对指定窗口 `PostMessage`，不带动真实键鼠，也不走 `ModeArr`。很多游戏/部分窗口无效，常需管理员。浏览器看起来点了但没反应，多半是窗口不吃后台消息。

后台鼠标：

- `MouseType` 1 左 2 中 3 右 4 滚轮。滚轮用 `ScrollV` / `ScrollH`（垂直非 0 时只滚垂直）。
- 点击/双击才睡 `ClickTime`（默认 50）。坐标可变量，套坐标浮动。
- `GetHwndList` 命中多个窗口时，每个都发一次。

后台按键：

- 规则与前台按键相同：按下/松开瞬发，要点击配对松开；组合键松开反向抬起。
- 点击时长套 `HoldFloat`，间隔套 `PreIntervalFloat`。默认点击时间 100、间隔 100。

### 窗口信息 / 调整窗口

`SearchValue` 为 `标题⎖类名⎖进程名`，可引用变量。匹配按窗口层叠顺序排列，普通模糊匹配筛选可见窗口。调整前先固定本次操作的窗口列表。启用 `CloseProcess` 时按去重后的 PID 结束进程。

### 按键检测

物理=`GetKeyState(key,"P")`：手指或罗技驱动。逻辑=再加宏模拟。  
`CheckType` 1 同时按下 / 2 有一个按下。结果写入变量 1/0。`KeyArr` 空则不写变量。仅键盘鼠标。

### 手柄检测

数据与按键检测相同（`KeyCheckData`，`JoyCheckFile.toml`）。手柄图选键，内部名 `JoyA` / `JoyDpadUp` / `JoyAxisLX:80`。摇杆各轴 `-100~100`，两轴合成按半径 125 限位（可 `100,67`，不可 `100,100`）。执行走 `OnJoyCheck` → `IsCheckKeyPressed`（AHK Joy / POV / 轴阈值）。

### 注释

`CommentFile.ini`，`On*` 直接空返回。指令串显示 `注释序号_前20字...`。不是 `🚫` 跳过。

### 抓图

`OnScreenShot` **只用 OpenCV**（`CaptureScreenMat` / `CaptureWinMat`），**不看**设置「截图方式」。插件不可用会失败并提示。

- 固定目录：`Setting/<方案>/Images/TempShot`。没写权限则 `A_Temp\RMT_TempShot\<方案>`。JSON 里的 `SavePath` **执行时不用**。
- `NameType==1` 且固定名非空 → `名称.png`；否则 `序列号-时间戳.png`。
- 坐标可变量；宽高必须 > 0。窗口抓图只截第一个 hwnd。
- `ResultToggle` 把完整路径写入变量，给搜索当图片源。

### 图形开始节点

`RunGraphFromStartNode` 从开始节点沿图执行，多个 Worker 可并行处理分支。
线性宏是一条队列；图形宏是图 + 引用计数，计数回 0 才结束。

## 4. 流程控制标记（写在该条宏的 VariableMapArr）

| 标记 | 谁设置 | 效果 |
|------|--------|------|
| `循环-跳过本轮` | 如果 / 如果Pro | 结束当前循环体或当前宏轮 |
| `循环-跳出` | 同上 | 离开循环或离开整个宏循环 |
| `分支-跳出` | 同上 | 离开当前 `RunMacroBodyOnce` |
| `宏循环次数` | 执行框架 | 外层第几轮，从 1 |
| `循环次数` | 循环指令 | 内层第几轮 |

## 5. 耗时与丢失

系统来不及处理会丢指令。建议：

- 点击时长 ≥ 100ms，不要低于 30ms
- 点完按钮后再搜，后面加 ≥ 500ms
- 宏末尾加约 200ms
- 平时多插 100ms 间隔

搜索耗时 ≈ (单次检索 + 间隔) × 次数 − 间隔。  
点击耗时 ≈ (时长 + 间隔) × 次数 − 间隔。

---

## 6. 失败时看起来像「没执行」的原因

1. `🚫` 或注释
2. 未知指令名 / JSON 序列号对不上（读到默认空对象）
3. 变量不存在且没开提醒 → 该条中途 return
4. 已被杀或暂停
5. 仅前台运行宏，窗口切走
6. `try/catch` 吞掉异常
7. 按键类型在目标程序无效
8. 搜索一直重试（无限次数）看起来像卡死
9. 抓图时 OpenCV 不可用，或宽高非法 / 窗口信息为空

---

## 7. 指令与页签无关

任何页签的 `MacroArr` 都走同一套 `Actions`。  
差别只在**怎么被触发**（热键 / 字串 / 轮盘 / 浮窗 / 定时 / 宏操作）。
