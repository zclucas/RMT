# 变量与表达式

源：`VariableUtil.ahk`、`ExpressUtil.ahk`、`DataClass` 的 Variable/Operation/Array、指令手册第 11~15、19 节。

---

## 1. 作用域

- 用户创建的变量、数组都是**全局**的，所有宏、所有 Worker 共享。
- Worker 改变量会 EVENT 回主进程再广播。
- 每条正在跑的宏另有 `VariableMapArr[index]`：**内置/流程标记**，不是用户变量盘。

内置（随宏走）：

| 名 | 含义 |
|----|------|
| `循环次数` | 最近一层「循环」指令的当前轮次 |
| `宏循环次数` | 该条宏外层 LoopCount 的当前轮，从 1 |
| `循环-跳过本轮` `循环-跳出` `分支-跳出` | 流程控制，布尔 |

---

## 2. 系统变量（只读，实时取）

| 名 | 内容 |
|----|------|
| 循环次数 | 见上 |
| 宏循环次数 | 见上 |
| 句柄ID | 当前鼠标窗口 HWND |
| 当前鼠标颜色 | 如 `EEFF44` |
| 当前鼠标坐标X / Y | 屏幕坐标 |
| 窗口宽度 / 高度 | 当前鼠标所在窗口宽、高 |
| 窗口坐标X / Y | 当前鼠标所在窗口左上角 X、Y（屏幕坐标） |
| 当前日期 | `2026-04-12` |
| 当前时间 | `19:46` |
| 当前时间(秒) / 当前时间秒 | `19:46:58` |
| 当前秒 | `58` |
| 当前星期几 | 系统星期 |

不能赋值。变量指令选「系统」是读取这些值到用户变量。

## 3. 命名规则

`CheckVarNameIfValid`：

- 不能空
- 不能纯数字
- 不能包含 `_`（会和指令参数分隔冲突）

合法：`HP` `坐标X` `Data` `Var1`  
非法：`1` `HP_1` ``

---

## 4. 替换语法

文本类指令（输出、运行路径、部分搜索文本）执行前替换：

- `{变量名}` → 变量值
- `{ε数组名}` → 数组内容

变量提取模板里的 `{Title}` 也是先替换再匹配。  
`&x` = 抽出一个数字，`&c` = 抽出一段文本。

例：模板 `HP：&x` 对文本 `HP：3,000` → 3000。

---

## 5. 谁会写变量

| 指令 | 写入 |
|------|------|
| 变量 | 数值/随机/字符/系统/删除 |
| 变量提取 | 最多 6 个 |
| 如果 | 可选结果 1/0 |
| 搜索(Pro) | 可选成败、坐标 X/Y |
| 运算 | 表达式结果 |
| 数组 | 取值、长度、包含等 |
| 文本处理 | 结果变量或数组 |
| 输入 | 弹窗/状态 |
| 文件读写 | 读出内容 |
| 按键检测 | 1/0 |
| 手柄检测 | 1/0 |
| 抓图 | 可选图片**完整路径**（`Images/TempShot` 或回退临时目录） |
| 运行Pro Mode 2/4 | 退出码、stdout、stderr |

`变量存在忽略`：已有则不改。  
提取失败：新变量变 0，已有变量保持。

## 6. 运算

`OperationData.ExpressionArr` 交给表达式引擎，支持括号和四则等。  
结果写入 `UpdateNameArr`，表达式里出现的变量本身不变。

用户说「我运算了 HP 怎么没变」：看他有没有填**结果变量**，是不是把结果写到了另一个名字。

---

## 7. 数组

- 下标从 **1**
- `MainIndex=0` 操作整个数组；`=N` 操作第 N 个元素（可当二维）
- 类型：创建、克隆、删除、包含、取值、赋值、插入、追加、移除、移除最后、反转、长度
- 全局，名不能和变量规则冲突

输出里用 `{εArr}` 展开。

---

## 8. 找不到变量时

- `NoVariableTip` 开：弹窗
- 关：该条指令常常直接 return，后续指令还跑
- 监视器在工具页，看的是全局表，看不到某条宏的 `VariableMapArr` 流程标记

---

## 9. 机器人排查口诀

1. 名字有没有 `_` 或纯数字
2. 是不是在用系统变量名当左值赋值
3. `{HP}` 有没有写成 `HP` 或 `{ HP }`
4. 提取失败是否被当成「没创建」
5. 多线程下改完立刻在另一条宏读，理论上会广播，但极短间隔仍可能看到旧值
6. 共享复制的多条指令共用序列号，改一处等于改全部
