# 软件设置选项

源：`Main/UIUtil.ahk` 的 `AddSettingUI`、各 `*SettingGui.ahk`、`BindUtil.ahk` 帮助文案、`LoadMainSetting()`。  
全局设置存在 `Setting/MainSettings.ini` 的 `[UserSettings]`，**不属于某个宏方案**。换方案不会丢掉这些项。  
改完必须「应用并保存」。

---

## 1. 数值选项

| 界面名 | 字段 / ini | 默认 | 作用 |
|--------|------------|------|------|
| 点击时间浮动(%) | `HoldFloat` | 0 | 按键「点击」按下到松开的时间 ±% |
| 每次间隔浮动(%) | `PreIntervalFloat` | 0 | 多次点击、多次搜索、多次提取的间隔 ±% |
| 间隔指令浮动(%) | `IntervalFloat` | 0 | 「间隔」指令时长 ±% |
| 坐标 X 浮动(px) | `CoordXFloat` | 0 | 模拟点击 X ±px |
| 坐标 Y 浮动(px) | `CoordYFloat` | 0 | 模拟点击 Y ±px |
| 多线程数(-1~10) | `MutiThreadNum` | -1 | 见下 |
| 软件背景颜色 | `SoftBGColor` | `f0f0f0` | 主界面背景 6 位 HEX |

浮动规则：未写 `+`/`-` 时正负都浮动。例如间隔 3000、浮动 10 → 约 2700~3300。坐标是绝对值像素，不是百分比。

### 多线程数

| 值 | 含义 |
|----|------|
| -1 | 动态：核心池约 3 + 弹性池，闲置约 30 秒回收，最多 16 |
| 0 | 单线程，宏在主进程跑 |
| n | 固定 n 个 `Work.exe`（推荐 3~5） |

界面上核心池、弹性超时已隐藏，仍可读 ini：`DynamicCorePoolSize`、`ElasticTimeout`。

## 2. 开关选项

| 界面名 | 字段 | 默认 | 作用 |
|--------|------|------|------|
| 开机自启 | `IsBootStart` | 关 | 写入注册表。不要用兼容性「以管理员运行」，否则自启失效 |
| 管理员启动 | `IsAdminStart` | 关 | 保存后提权。后台键鼠、很多游戏需要。与自启同时开则自启也是管理员 |
| 仅前台运行宏 | `CheckForeground` | 关 | 运行中检查该宏/模块的前台；不匹配就终止。没填前台的宏不受影响 |
| 自动松开修饰键 | `AutoLoosenModifier` | 开 | `Ctrl+A` 这类触发前先松开修饰键。`~` 穿透键不松开 |
| 连续触发 | `ContinuousTrigger` | 开 | 按下/开关/长按按住可连触。关则必须先松开。滚轮不受影响 |
| 无变量提醒 | `NoVariableTip` | 开（ini 默认 true） | 用了不存在的变量时弹窗 |
| 模态子窗口 | `IsModalSubGui` | 开 | 开着时必须先关编辑窗才能点主窗，防丢编辑 |
| 分割线 | `ShowSplitLine` | 关 | 宏列表分隔线 |

「右键菜单设置」按钮在同一行，见第 6 节。

## 3. 下拉框选项

| 界面名 | 字段 | 选项（值） |
|--------|------|------------|
| 语言/Lang | `Lang` | 语言文件名，如 `中文` |
| 软件字体 | `FontType` | 系统字体，默认微软雅黑 |
| 首选编辑器 | `PreferredMacroEditor` | 1 逻辑树 / 2 图形节点（仅新建空宏时） |
| 截图方式 | `ScreenShotType` | 1 微软 / 2 RMT / 3 SC（默认 3）。给 **RMT指令·截图** 和工具热键 Alt+Y 用。报错就换。**「抓图」指令不走这项**，它固定用 OpenCV |
| 手柄映射 | `TriggerJoyType` | Xbox / PS5。**只改显示名**（触发键、按键指令、按键检测、手柄检测） |
| 宏手柄类型 | `JoyType` | Xbox / DS4。**实际输出到 ViGEm 的手柄类型** |
| 按下时按下 | `KeyDownDownType` | 1 自动松开 / 2 忽略重复按下 / 3 允许重复按下 |
| 指令备注 | `RemarkAutoType` | 1 不生成 / 2 自动生成 / 3 覆盖生成 |
| 宏终止方式 | `MacroStopType` | 1 智能终止 / 2 强制终止 |

### 按下时按下

宏已经把某键按下，又执行一次「按下」时：

- 自动松开：先松再按，保证指令能出去（默认，推荐）
- 忽略重复按下：保持按住，忽略后面的按下
- 允许重复按下：再发一次按下。罗技模式可能卡死

真实键盘几乎不会「按下后再按下」。记事本可能看得到，网页按键检测常常看不到。

### 宏终止方式

- 智能：先让宏自己退，150ms 不行再强杀 Worker
- 强制：立刻杀进程再建。快，但频繁重建费资源

### 两个手柄选项不要混

- 手柄映射 = 界面上 A/×、LB/L1 怎么写
- 宏手柄类型 = 游戏里收到的是 Xbox 360 还是 DualShock 4 虚拟设备  
需要先装 `Plugins/ViGEm` 里的 ViGEmBus。

## 4. 功能选项按钮

### 4.1 主题

打开主题色板（`ThemeSettingGui` / `AppTheme`）。影响轮盘、浮窗、指令窗颜色。`Theme` 默认 `RMT_Light`。

### 4.2 快捷键

| 项 | 默认 | 说明 |
|----|------|------|
| 软件休眠 | Alt+P | 只能用按键，不能用字串 |
| 暂停宏 | Alt+I | 可字串 |
| 终止宏 | Alt+K | 可字串 |
| 语音输入 | 左 Alt | 输入弹窗按住说话；单键（任意键都可，字母数字会影响弹窗内打字），仅弹窗聚焦时生效 |
| 指令录制 | Alt+R | |
| 文本提取 | Alt+U | |
| 屏幕截图 | Alt+Y | |
| 自由贴 | Alt+T | |
| 鼠标信息 | Alt+O | |

空 = 不绑定。修饰符：`!` Alt，`^` Ctrl，`+` Shift，`#` Win。

### 4.3 指令录制

| 项 | 默认 | 说明 |
|----|------|------|
| 自动松开 | 开 | 结束录制时补松开 |
| 合并按住多键 | 关（界面）/ 类默认曾为开 | 同时按住的键是否合成一条 |
| 录制键盘 / 鼠标 | 开 | |
| 鼠标轨迹 | 关键点位 | 0 不录 / 1 关键点 / 2 相对位移 / 3 全量 |
| 轨迹速度 | 95 | |
| 录制手柄 | 关 | 需额外配置手柄 |
| 手柄间隔 | 50ms | |
| 显示边框 | 开 | 录制时屏幕框 |

### 4.4 轮盘（菜单宏全局）

| 项 | 默认 | 说明 |
|----|------|------|
| 显示扇区名称提示 | 关 | |
| 固定位置（屏幕中下方） | 关 | 开则不跟鼠标 |
| 选择模式 | 划线选择 | 点击选择 / 划线选择 |
| 轮盘大小 | 100% | 50~200 |

### 4.5 界面浮窗

| 项 | 默认 | 说明 |
|----|------|------|
| 激活时默认显示 | 开 | 目标窗口到前台时弹出 |
| 按钮宽/高/字号/每行列数 | 80 / 34 / 12 / 3 | |

颜色跟主题走。

### 4.6 指令显示

左边小勾选 = 是否启用 `CMDTip`。按钮打开详细设置：

- 位置、宽高、字号、背景透明度（0 不透明 ~ 100 全透明）
- 是否写日志、日志路径（空=`Log/CMDLog.txt`）
- 自动清理：从不 / 每天 / 每周
- F1 可用鼠标位置设窗口坐标

运行中的指令行会换背景色。

### 4.7 日志与错误

系统日志可以独立勾选调试、信息、警告和错误级别。新配置默认记录警告和错误，升级时沿用旧配置实际记录的级别。

## 5. 右键菜单设置

逻辑树编辑器右键：

- 一般指令：编辑、跳过指令、调试起点、插入、复制、共享复制、粘贴、删除、分隔线
- 分支/循环体：添加、复制、共享复制、粘贴、删除

「共享复制」：不重新分配序列号，改一处同序列号指令一起变。设置里 `SharedCopy` 控制是否显示该项。

`🚫` = 跳过（执行直接 return）。`⭐` = 调试起点。

## 6. 不在设置页、但算全局行为

| 位置 | 项 | 说明 |
|------|----|------|
| 主界面左下 | 应用并保存 | 写入并重绑，否则改动不生效 |
| 主界面 | 休眠 / 暂停 / 终止全部 / 重载 | 见软件介绍 |
| 配置名（点标题） | 配置管理器 | 新建、导入、合并、导出 `.rmt`、迁入文件夹 |
| 工具页 | 变量监视器置顶/大小 | `VarListenTop` `VarListenWidth/Height` |
| 每条宏「宏设置」 | 按键类型、提示音 | 存在 `MacroFile.ini` 的 `ModeArr` 等，不是 MainSettings |

## 7. 按键类型（每条宏，不是全局）

| 值 | 名称 | 适用 | 注意 |
|----|------|------|------|
| 1 | AHK Send | 办公、多数游戏 | 管理员可提高进游戏成功率 |
| 2 | keybd_event | 老软件/老游戏 | 要管理员；模拟出的键能再触发宏 |
| 3 | 罗技 | 依赖 G HUB | 只要 **G HUB ≤ 2022.2.1154**，设备管理器里要有两个 GHUB 虚拟设备 |
| 4 | AHI | Interception | 要管理员并安装 Interception；模拟键也能再触发宏 |
| 5 | VIIPER | 虚拟 USB 键鼠 | 需安装 usbip-win2 并启动 VIIPER 服务 |

自己触发自己会死循环。侧键若被鼠标厂家软件占用，任何类型都收不到触发。

---

## 8. 机器人答设置题时的顺序

1. 确认用户说的是「设置页全局」还是「某条宏的宏设置」。
2. 全局项对所有方案生效；宏设置只对那一条。
3. 游戏里无效：先管理员启动，再改该条按键类型（AHI 或罗技），不要先让用户乱改浮动和多线程。
4. 不要建议用户去 exe 属性勾「以管理员运行」。
