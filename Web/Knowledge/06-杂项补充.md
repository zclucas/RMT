# 杂项补充

用户手册没展开、但群里常问的边角。

---

## 1. 配置里的特殊分隔符

| 符号 | 用途 |
|------|------|
| `π` | ini 里数组元素分隔（TKArr、ForbidArr 等） |
| `,` `，` 换行 `⫶` | 宏指令分隔。写入 ini 时换行会变成 `⫶` |
| `_` | 指令参数分隔。变量名因此不能含下划线 |
| `⎖` | 窗口信息三项：标题、类名、进程名 |
| `❖` | 后面是句柄列表，`\|` 再分隔 |
| `~` | 触发键穿透（不吃掉原键） |
| `:` | 字串宏 / 热字串前缀 |
| ` & ` | 组合键（AHK 语法） |
| `{变量}` `{ε数组}` | 输出、路径等处的替换 |
| `🎮` | 界面上手柄键的显示前缀，存盘仍是 JoyA 等 |

读用户粘贴的 ini 时：先按 `π` 拆列，再按逗号/`⫶` 拆指令。

## 2. 前台（窗口限制）

两层：

1. **触发过滤**：`FoldInfo.FrontInfoArr`（模块）或宏级前台。当前鼠标窗口不匹配则该条不进有效列表。全都匹配失败时，回退到「没填前台」的宏。
2. **运行检查**：设置「仅前台运行宏」开启后，执行每条指令前再查一次，不匹配就杀宏。

空前台 = 所有窗口都能触发。  
填错进程名（多一个 `.exe` 或缺）= 看起来像宏坏了。  
排查：先清空前台，确认能触发，再重填。

## 3. 两种编辑器

| | 逻辑树 | 图形节点 |
|--|--------|----------|
| 存储 | `MacroArr` 线性指令串 | `图形开始节点` + 各节点 JSON |
| 分支 | 指令内嵌 TrueMacro/FalseMacro 字符串 | 节点连线，可并行 |
| 复制 | 默认可重新分配序列号；共享复制不改号 | 节点复制 |
| 首选 | `PreferredMacroEditor` | |

空宏按「首选编辑器」打开。已有内容按已有格式打开。  
重载会丢未保存的树编辑；图形编辑器内存改动是否回滚以当前版本说明为准。

## 4. 提示音

每条宏独立：

- 开始：无 / 每次触发都响 / 只在循环第一轮响
- 结束：无 / 每轮结束都响 / 只在整个循环结束响
- 开关被杀掉时，若结束音是「循环结束提示」，会补播一次

文件：`Audio/Start.wav`、`Audio/End.wav`。

---

## 5. 模块（折叠框）

- 「禁用模块」：该模块下热键不注册，但「宏操作」仍能调里面的宏。
- 「禁用宏」：这条完全不参与触发和执行。
- 菜单宏 / 界面宏：触发键在模块上，模块下每条宏是轮盘扇区或浮窗按钮。
- `IndexSpanArr` 如 `1-5` 表示这个模块管第 1 到第 5 条。

---

## 6. 顺序触发（UnorderedTriggerArr）

组合键 `Ctrl & A`：

- 勾选顺序触发（值为 1）：只注册书写顺序
- 不勾选（0）：正序、反序都注册，先按 A 再按 Ctrl 也能触发

---

## 7. 配置管理（点主界面配置名）

| 操作 | 注意 |
|------|------|
| 迁入配置文件夹 | 选另一份 RMT 的 `Setting` 整夹覆盖；当前先备份到 `SettingOld` |
| 配置校准 | 迁入/改名后异常时用 |
| 导入 `.rmt` | 整包方案 |
| 合并导入 | 合进当前方案，序列号会重分配以免撞车 |
| 导出 | 分享用，建议填使用说明 |
| 不要直接覆盖安装目录更新 | 容易热键全废，用迁移或导入 |

共享仓库：https://zclucas.github.io/RMT-Setting/

## 8. 工具页

- 变量监视器：看全局变量，默认可置顶
- 文件校验：补插件/模型/音频。测试版（带 F 后缀）对不上正式资源仓库
- 鼠标信息：坐标、颜色、标题、类名、进程、句柄
- 指令录制：按录制选项生成指令串
- 图片文本提取：OCR 到剪贴板
- 窗口置顶：主窗口置顶

## 9. 安全软件与权限

360 / 火绒 / 腾讯管家常拦左键、右键、回车的模拟。  
处理：关拦截或加白名单 + 管理员启动。  
不要用 exe「兼容性-以管理员运行」，会破坏开机自启。

---

## 10. 版本与 Worker

当前代码版本常量：`RMT.ahk` 里 `RMT_VERSION`（撰写时为 1.3F2）。  
改了 `Thread/Work.ahk` 需要重新编译 `Work.exe`，或删 exe 让运行时再生成，否则主程序和新 Worker 协议可能不一致。

## 12. 默认示例宏（从未保存过的新方案）

按键/字串/定时/子宏/界面：`按键_a_点击_100_10_200,间隔_3000`  
按键替换：`Left,a`  
按键宏第一条默认禁用，备注「取消禁用配置才能生效」，触发键 `k`。

用户说「我装完按 k 没反应」：那条默认是禁用的。
