# 🚀 指令手册 - RMT（若梦兔）

本页介绍 **RMT（若梦兔）** 各个指令做什么、参数怎么填、执行时会怎样。

阅读时注意：
- 「搜索 / 搜索Pro」「移动 / 移动Pro」「如果 / 如果Pro」是同一类能力的简化版和完整版，不是两套互不相干的指令。
- 「指令格式」是宏字符串里实际保存的写法。间隔、按键、移动、RMT指令、注释把参数直接写在字符串里；其它指令在宏里只写序列号（如 `搜索1`），详细参数保存在配置中。
- 带序列号的指令可以加「备注」，那只是这条指令的名字，方便辨认，不影响执行。

## 1 间隔

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Interval.png)  

### 功能说明
1. **插入间隔**：插在两条指令中间。执行到本条时先等待，再继续后面的指令。
2. **循环间隔**：把本条放在整段宏的最后。外层每一轮指令都跑完后，会先等这段时间，再开始下一轮。它不会改变宏配置里的「循环次数」。

### 类型说明
1. **固定**：每次都等待同一个时长。
2. **随机**：在「时间 1」和「时间 2」之间抽一个时长；每执行一次重新抽。

### 参数解析
1. **整数**：等待时长，单位是毫秒。例如 `3000` 表示 3 秒，`0` 等于不等待。
2. **变量**：读取变量的当前值，当作等待时长（同样是毫秒）。

### 特别说明
1. **间隔指令浮动**：设置页「间隔指令浮动(%)」只作用于本指令。未写正负号时上下都浮动，例如间隔 `3000`、浮动 `10`，实际约 `2700～3300` ms。按键连点、搜索多次之间的等待走的是「每次间隔浮动」，与本项无关。
2. **循环间隔**：宏要循环几遍，由这条宏配置上的「循环次数」决定，本指令改不了这个数字。放在末尾只是让每一轮跑完后再等待，再进入下一轮；随机间隔每轮会重新抽取。

### 指令格式
- 固定：`间隔_时长`
- 随机：`间隔_时间1~时间2`
- 示例：`间隔_500`、`间隔_500~1000`

## 2 按键

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Key.png)  

### 功能说明
1. **按下 / 松开 / 点击**：对界面里勾选的那些键，执行对应动作。
2. **组合键**：可以同时勾选多个键。执行时按勾选顺序一起按下；松开时按相反顺序抬起。

### 类型说明
1. **按下**：按下指定按键后立刻继续下一条（瞬发，本条不消耗时间）。
2. **松开**：松开指定按键后立刻继续下一条（瞬发）。
3. **点击**：先按下，等待「点击时间」后再松开；可以连续重复多次。

### 参数解析
1. **类型**：按下 / 松开 / 点击。只有选「点击」时，下面三项才生效。
2. **点击时间**：从按下到松开经过的时间（毫秒）。省略时默认 `100`。
3. **点击次数**：连续点击多少次。省略时默认 `1`。
4. **每次间隔**：松开之后、下一次再按下之前的等待（毫秒）。省略时默认 `0`。只在点击次数大于 1 时有意义。

### 特别说明
1. **瞬发**：按下、松开执行完立刻走下一条，本条本身不等待。
2. **不是连发**：选「按下 `a`」只是把 `a` 按住，不会像物理键盘长按那样自动反复输入 `a`。系统长按时，其实是在不断松开再按下；本指令不会这么做。
3. **配对松开**：用「按下」之后，建议后面再配一条「松开」。只按不松就再按一次，后续按下可能无效（卡键）。
4. **点击与长按**：这不是本指令里的两种类型，而是目标程序怎么理解这次按住。多数程序里，点击时间短于约 200ms 会被当成单击，长于约 250ms 会被当成长按；200～250ms 介于两者之间，表现因软件而异。
5. **点击耗时**：本条实际占用的时间 ≈（点击时间 + 每次间隔）× 点击次数 − 每次间隔。最后一次松开后不会再等「每次间隔」。
6. **浮动**：点击时间受设置「点击时间浮动(%)」影响；每次间隔受「每次间隔浮动(%)」影响。按下、松开是瞬发，不受点击时间浮动影响。这两项也不是「间隔指令浮动」。
7. **结束松键**：这里说的是宏的**触发类型**（按下 / 松开 / 双击 / 长按 / 开关），不是本指令的按下 / 松开 / 点击。触发类型为按下、松开、双击、长按时，宏**正常跑完不会**自动松开仍按住的键。只有被终止，或触发类型是**开关**并结束时，才会兜底松开。因此「只按下不松开」在开关宏里看起来没事，换其它触发类型就容易卡键。
8. **宏设置 · 按键类型**：本指令不选择模拟方式，发送走的是该条宏「宏设置」里的按键类型。
   - **AHK Send**：通用，适合办公和多数游戏（管理员权限可让更多游戏有效）
   - **keybd_event**：系统接口，适合老软件或游戏（需管理员）
   - **罗技**：走罗技驱动（需管理员，G HUB 需为 2022.2.1154 及以前版本）
   - **AHI**：走 Interception 驱动（需管理员，并安装 Interception）
   记事本能触发、游戏里无效时，优先勾选「管理员启动」，再改这条宏的按键类型，而不是改本指令的点击时间。
9. **按下时按下**：宏已经把某键按住，又执行一次「按下」时，由设置「按下时按下」决定：自动松开（默认，先松再按）、忽略重复按下、允许重复按下（罗技模式可能卡死）。
10. **自触发**：keybd_event、罗技、AHI 模拟出的键可以作为宏的触发键。触发键不要和本指令输出的键相同，否则会自己触发自己形成死循环。
11. **点击时间建议**：建议不低于 **100ms**，低于 **30ms** 时后续指令容易丢失。不追求极限速度时，点击后再加一条间隔更稳。

### 手柄按键说明
1. 使用前需要安装软件 Joy 目录下的 **ViGEmBus.exe**，否则本指令里勾选的手柄键发不出去。
2. 设置里的**宏手柄类型**（Xbox / DS4）决定游戏实际收到哪种虚拟手柄；**手柄映射**只改界面上按键名称怎么显示（例如 A 还是 ×），不改实际输出。
3. 摇杆、方向键、扳机和普通按钮一样写在本指令里，由软件按手柄键发送，不走上面的 AHK / 罗技 / AHI 键盘通道。

### 键盘按键检测
1. 点击界面上的输入框。
2. 按下要模拟的目标按键或组合键。
3. 点击「确定」，软件会自动勾选对应按键，不必在列表里一个个找。

### 指令格式
- 按下：`按键_按键名_按下`
- 松开：`按键_按键名_松开`
- 点击：`按键_按键名_点击_点击时间_点击次数_每次间隔`
- 多键：键名之间用 `⎖` 连接，例如 `按键_Ctrl⎖a_点击_100`
- 示例：`按键_a_按下`、`按键_a_点击_100`、`按键_a_点击_100_10_200`

## 3 搜索

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Search.png)  

### 功能说明
1. **屏幕搜索**：在屏幕指定范围内查找图片、颜色或文本。
2. **分支执行**：找到或没找到时，可以分别执行一段指令（不填则只搜、不分支）。
3. **简化配置**：本指令是「搜索Pro」的简化版。默认只搜 1 次、相似度约 90。窗口搜索、改相似度、多次重试、把结果或坐标写入变量等，见「搜索Pro」。

### 类型说明
1. **屏幕图片**：在范围内匹配目标图片。图片可以选本地文件，或用 F2 当场截图。
2. **屏幕颜色**：在范围内查找指定颜色。颜色可以手填 HEX，或用 F3 取当前鼠标位置的颜色。
3. **屏幕文本**：在范围内匹配文字，支持正则表达式。

### 参数解析
1. **搜索范围**：从起始坐标到终止坐标围成的矩形。起始坐标不能大于终止坐标；做图片搜索时，范围不能小于图片本身。坐标可填整数或变量。
2. **搜索目标**：图片选本地文件或截图；颜色填 HEX 或用 F3 取色；文本直接输入（支持正则，也可引用变量）。
3. **鼠标动作**：找到后要对鼠标做什么：无动作 / 移动到目标 / 移动到目标并点击 1 次 / 移动到目标并点击 2 次。
4. **分支指令**：「找到后」和「未找到后」两段指令都可以留空。留空表示搜完就继续后面的主流程。
5. **备注**：写在指令串序列号后面，只用于辨认，不影响搜索。

### 特别说明
1. **搜索不是识别**：源素材要和屏幕上的目标基本一致才能搜到。它比的是像素是否像，不是「看懂画面」。
2. **分支前加间隔**：找到后会先做鼠标动作，再执行「找到后」分支。目标程序反应慢时，分支开头需要加间隔，避免点完立刻做下一步。
3. **文本支持正则**：搜索文本可按正则匹配。
4. **范围与素材**：范围越小、图片越小，速度越快。截图只截特征部分，不要带会变化的背景（推荐 32×32 或 48×48）。
5. **dll 加载失败**：图片或文本搜索提示 dll 失败时，请看「问题及应对措施」，或到工具页做文件校验补齐插件。
6. **图片丢失**：提示图片不存在时，若软件目录变过，到配置管理做「配置校准」。
7. **和搜索Pro**：两者用同一套执行引擎。本指令默认搜 1 次、相似度约 90，不能做窗口搜索、不能无限重试、不能把成败或坐标写入变量；需要这些时用搜索Pro。

### 快捷键
1. **F1**：开启框选范围（左键松开后关闭）。
2. **F2**：截图作为搜索图片素材，并根据图片位置、大小自动选取搜索范围。
3. **F3**：选取当前鼠标位置颜色值作为颜色搜索的素材。
4. **定位取色器**：更精细地确定坐标、拾取颜色。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`搜索序号`，带备注时为 `搜索序号_备注`
- 示例：`搜索1`、`搜索1_找血条`

## 4 搜索Pro

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/SearchPro.png)  

### 功能说明
1. **屏幕搜索**：在屏幕指定范围内查找图片、颜色或文本，并按找到 / 未找到执行分支。
2. **窗口搜索**：在符合窗口信息的窗口里搜索。目标窗口可以在后台或最小化，不必露在最前面。
3. **结果保存**：可以把成功 / 失败写入变量；找到时也可以把目标中心点坐标写入变量。
4. **完整配置**：和「搜索」用同一套执行引擎。搜索是简化版；本指令可以改相似度、次数、间隔、识图模型、窗口信息和多分辨率规格。

### 类型说明
1. **屏幕图片 / 屏幕颜色 / 屏幕文本**：在屏幕坐标范围内搜索。
2. **窗口图片 / 窗口颜色 / 窗口文本**：在指定窗口内部搜索，可在后台或最小化时使用。窗口搜索的范围需要自己框选，不会按屏幕自动对应。

### 参数解析
1. **屏幕规格**：同一条指令适配不同分辨率。换设备或导入他人配置时，建议新增一条规格，再重设搜索目标和范围；自己一台电脑用可以忽略。
2. **搜索范围**：从起始坐标到终止坐标围成的矩形。起始不能大于终止；做图片搜索时，范围不能小于图片。坐标可填整数或变量。
3. **搜索目标**：图片选本地文件或截图（路径也可引用变量）；颜色填 HEX 或用 F3 取色；文本可输入内容（支持正则）或引用变量。
4. **相似度**：值越大匹配越严格，越不容易误搜到别的东西。只对图片、颜色生效，文本搜索不用这项。
5. **搜索次数**：没找到就再试，直到找到或次数用尽。也可以选「无限」，一直等到出现。
6. **每次间隔**：两次搜索之间的等待。只在次数大于 1 或选了无限时生效。受设置「每次间隔浮动(%)」影响，不是「间隔指令浮动」。
7. **鼠标动作**：
   - 屏幕：无动作 / 移动到目标 / 移动到目标并点击（可设移动速度、点击次数；速度 100 为瞬间到达）
   - 窗口：无动作 / 后台鼠标到目标点击 / 后台鼠标到目标双击（不移动真实光标）
8. **窗口信息**：窗口搜索时必填。可以填窗口句柄，或按 `标题⎖类名⎖进程名` 三项来匹配（某一项可以留空）。同时匹配到多个窗口时，鼠标动作会对每个匹配窗口各做一次。
9. **图片识别模型**：OpenCV（推荐，仅 64 位）：相似度 0～94 按灰度比（快，不校对颜色），95～100 同时比图像和颜色。RMT 识图走 AHK `ImageSearch`，很慢。
10. **文本识别模型**：中文模型识别中文 / 英文 / 数字（字库大、稍慢，`Plugins\RapidOcr\ch_models\ppocr_keys_v1.txt`）；英文模型识别英文 / 数字（更快，`Plugins\RapidOcr\en_models\ppocr_keys_v1.txt`）。缺字请加到对应字库文件顶部。
11. **分支指令**：「找到后」和「未找到后」两段指令都可以留空。
12. **结果保存**：勾选后，找到写入真值、没找到写入假值。
13. **目标点保存**：勾选后，只在找到时把目标中心点的屏幕坐标写入变量；没找到不改原值。
14. **备注**：写在指令串序列号后面，只用于辨认，不影响搜索。

### 特别说明
1. **搜索不是识别**：源素材要和目标基本一致才能搜到。它比的是像素是否像，不是「看懂画面」。
2. **无限次数**：会一直搜到找到为止，之后只走「找到」分支，「未找到」分支不会触发。暂停、终止可以打断。
3. **耗时**：本条实际占用的时间 ≈（单次检索时间 + 每次间隔）× 实际搜索次数 − 每次间隔。最后一次搜完后不会再等「每次间隔」。
4. **分支前加间隔**：找到后先做鼠标动作，再执行「找到后」分支。目标程序反应慢时，分支开头需要加间隔。
5. **范围与素材**：范围越小、图片越小，速度越快。图片推荐只截特征，大约 32×32，不要带会变的背景。文本推荐多字一起搜，单字符容易不准。
6. **截图后改大小**：用 SC 截图后如果又改了图片大小，搜索范围需要重新框选，否则范围和素材对不上。
7. **dll 加载失败**：请看「问题及应对措施」，或到工具页做文件校验。
8. **图片丢失**：软件目录变过时，到配置管理做「配置校准」。
9. **和搜索**：本指令参数更多。只做一次屏幕搜索、不用把结果写入变量时，用「搜索」即可。

### 快捷键
1. **F1**：开启框选范围（左键松开后关闭）。
2. **F2**：截图作为搜索图片素材，并根据图片位置、大小自动选取搜索范围。
3. **F3**：选取当前鼠标位置颜色值作为颜色搜索的素材。
4. **定位取色器**：更精细地确定坐标、拾取颜色。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`搜索Pro序号`，带备注时为 `搜索Pro序号_备注`
- 示例：`搜索Pro1`、`搜索Pro1_找血条`

## 5 移动

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Move.png)  

### 功能说明
1. **移动指针**：按填写的坐标，把鼠标指针移到目标位置。
2. **简化版**：坐标只能填整数，到了之后也不会顺便点击。需要填变量、到达后点击、重复移动或拟真轨迹时，用「移动Pro」。

### 类型说明
1. **绝对移动**：目标点就是填写的屏幕坐标，和当前指针在哪无关。
2. **相对移动**：目标点 = 当前鼠标位置 + 填写的偏移量。例如当前在 `(100,100)`，填写 `10,0`，会移到 `(110,100)`。
3. **游戏视角**：按相对位移转动第一 / 第三人称游戏镜头，不是把指针移到某个屏幕点。

### 参数解析
1. **坐标位置 X / Y**：绝对移动时是目标点，相对移动和游戏视角时是偏移量。只能填整数。受设置「坐标 X / Y 浮动」影响。
2. **移动速度**：0～100，数值越大越快，100 为瞬间到达。默认 `90`。
3. **移动方式**：绝对移动 / 相对移动 / 游戏视角。
4. **备注**：本指令没有单独的备注框，参数直接写在指令串里。

### 特别说明
1. **按键类型**：实际怎么移动，跟随该条宏「宏设置」里的按键类型（AHK / 罗技 / AHI 等）。
2. **和移动Pro**：本指令不能填变量、不能顺便点击。游戏里转镜头、要拟真轨迹时用移动Pro。

### 快捷键
1. **F1**：将当前鼠标坐标设成指令目标点。

### 指令格式
- 格式：`移动_坐标X_坐标Y_移动速度_移动方式`
- 移动方式：`0` 绝对，`1` 相对，`2` 游戏视角；省略时默认绝对、速度 `90`

## 9 循环

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Loop.png)  

### 功能说明
1. **重复执行**：按指定次数，反复执行循环体里的那一段指令。
2. **条件控制**：可以在每一轮开始时先判断条件，再决定本轮要不要跑、或要不要离开循环。

### 类型说明
1. **无**：不设条件，只按「循环次数」执行。次数到了就结束。
2. **继续条件**：每一轮先判断。条件成立才执行循环体；不成立则离开循环。
3. **退出条件**：每一轮先判断。条件成立则立刻离开循环，不再执行本轮循环体。

### 参数解析
1. **循环次数**：循环体最多执行多少次。这是本指令自己的次数，不是宏配置上那个「循环次数」。
2. **循环条件**：无 / 继续条件 / 退出条件。最多 4 路判断，比较方式和「如果」相同。
3. **逻辑关系**：多路条件之间用「且」（全部成立才算成立）或「或」（有一路成立就算成立）。
4. **循环体**：每一轮要跑的指令组合。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **循环次数变量**：循环体里面可以用系统变量「循环次数」表示当前是本指令的第几轮。它和上面参数里的「循环次数」、宏配置上的「循环次数」不是同一个东西。
2. **流程控制**：循环体里的「如果」如果选了「循环-跳过本轮」或「循环-跳出」，作用的是这一层循环，不会直接结束整条宏（除非当前已经不在循环指令里）。
3. **和外层循环**：宏配置上的「循环次数」是整条宏再从头跑几遍；本指令是宏内部再套一层循环。
4. **暂停 / 终止**：循环过程中可被暂停或终止打断。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`循环序号`，带备注时为 `循环序号_备注`
- 示例：`循环1`、`循环1_点十次`

## 10 宏操作

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/SubMacro.png)  

### 功能说明
1. **复用宏**：把另一条宏的指令接到当前流程里接着跑，或另外开一条同时跑。
2. **管控宏**：暂停、恢复或终止已经指定好的那条宏。

### 类型说明
1. **插入到当前宏**：把目标宏的指令展开进当前这条指令流，接着同步执行。目标宏如果是无限循环，也只插入一轮，避免把无限展开进来。
2. **触发**：另外启动目标宏，和当前宏同时跑（会再占一个执行线程）。
3. **暂停**：暂停正在运行的指定宏。目标当前没在跑，则本条没有效果。
4. **取消暂停**：恢复已经被暂停的指定宏。目标当前不是暂停状态，则本条没有效果。
5. **终止**：终止正在运行或已暂停的指定宏。目标两边都不是，则本条没有效果。

### 参数解析
1. **宏类型**：目标宏在哪个页签。可选按键宏 / 字串宏 / 菜单宏 / 界面宏 / 定时宏 / **宏**（子宏页签）/ **当前宏**（正在执行的这一条）。这里的「宏」指主界面那个没有热键的页签，不是泛指所有宏。
2. **宏序号**：目标宏在该页签列表里的序号。软件还会用序列码校正序号错位，避免中间删过条目后找错人。
3. **插入次数**：仅「插入到当前宏」时有效，表示把目标宏展开进来几遍。可填变量。
4. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **当前宏**：目标选「当前宏」时，操作的就是正在执行的这一条，不按序号去别的页签找。
2. **插入与触发**：插入不会多开一条并行宏，只是把指令接到当前流程后面；触发会再占一个 Worker / 线程，两边同时跑。
3. **子宏页签**：主界面「宏」页签里的条目自己没有热键，专门给人用本指令插入或触发。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`宏操作序号`，带备注时为 `宏操作序号_备注`
- 示例：`宏操作1`、`宏操作1_插入登录`

## 11 变量

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Variable.png)  

### 功能说明

1. **变量存在忽略**：勾选后，如果目标变量已经有了，这一路不再改它。适合做「只在第一次初始化」。

3. **变量名**：不能为空、不能是纯数字、不能包含 `_`（下划线和指令参数分隔符冲突）。

1. **系统变量只读**：不能把系统变量当作赋值目标，这样写不会生效。
2. **无变量提醒**：后面的指令引用了不存在的变量时，要不要弹窗，由设置「无变量提醒」决定。关了提醒时，看起来会像那条指令没执行。
3. **系统变量一览**：
   - **循环次数**：最近一层「循环」指令的当前轮次

   - **句柄ID**：当前鼠标所在窗口句柄
   - **当前鼠标颜色**：如 `EEFF44`
   - **当前鼠标坐标X / Y**：屏幕坐标
   - **当前日期**：如 `2026-04-12`
   - **当前时间**：如 `19:46`
   - **当前时间(秒)**：如 `19:46:58`
   - **当前秒**：如 `58`
   - **当前星期几**：系统星期

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`变量序号`，带备注时为 `变量序号_备注`

## 12 变量提取

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/ExVariable.png)  

### 功能说明
1. **抽取文本**：先从屏幕、剪贴板或窗口得到一段文字，再按模板从中取出数字或文字，写入变量。
2. **可重试**：识别失败或模板对不上时，可以按次数、间隔再试。

### 类型说明
1. **屏幕**：对屏幕上的一块矩形做 OCR，再按模板提取。
2. **剪切板**：不对屏幕识字，直接对剪贴板里已有的文本提取。
3. **窗口**：对指定窗口客户区做 OCR 后再提取。窗口可以在后台，不必露在最前面。

### 参数解析
1. **提取源**：屏幕 / 剪切板 / 窗口。
2. **提取文本**：提取模板。留空则把识别到的全部文本写入第一个开启的变量。`&x` 占一个数字，`&c` 占一段文本；模板里的 `{变量名}` 会先替换成变量值，再拿去匹配。
3. **搜索次数 / 每次间隔**：没提取成功就再试，直到成功或次数用尽。间隔受「每次间隔浮动」影响。
4. **窗口信息**：仅窗口提取时使用。可以填句柄，或按 `标题⎖类名⎖进程名` 匹配。同时匹配到多个窗口时，会对每个窗口各处理一次。
5. **识别模型**：中文模型识别中文 / 英文 / 数字（字库大、稍慢）；英文模型识别英文 / 数字（更快）。字库分别在 `Plugins\RapidOcr\ch_models\ppocr_keys_v1.txt`、`en_models\ppocr_keys_v1.txt`。缺字请加到对应文件顶部。
6. **提取范围**：仅屏幕提取时使用的矩形。可用 F1 框选。
7. **结果保存**：最多 6 路。可勾选「变量存在忽略」（已有则不改）；没勾选的路不会写入。
8. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **可能失败**：OCR 看错字，或识别结果对不上模板时，这次提取会失败，不会写入提取值。
2. **失败时怎么写变量**：
   - 变量还不存在，且这次失败：创建该变量，值为 `0`
   - 变量已经存在，且这次失败：不改原来的值
   - 提取成功：写入这次提取到的值
3. **模板示例**：
   - `&x`：取出第一个数字
   - `&c`：取出第一段文本
   - `HP：&x`：从 `HP：3,000` 取出 `3000`
   - `坐标(&x,&x)`：从 `坐标(10.5,8.6)` 取出两个数
   - `{Title}：&x`：若变量 `Title` 当前是 `血量`，则去匹配 `血量：20.5` 并取值
4. **无限次数**：会一直抽到成功为止；暂停、终止可以打断。

### 快捷键
1. **F1**：左键框选提取范围。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`变量提取序号`，带备注时为 `变量提取序号_备注`
- 示例：`变量提取1`、`变量提取1_读血量`

## 13 如果

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/If.png)  

### 功能说明
1. **条件分支**：按判断结果执行「成立」或「不成立」那一段指令。两段都可以留空，只判断、不分支。
2. **流程控制**：判断结束后，还可以同时让外层循环跳过本轮、离开循环，或结束当前这一层指令。

### 类型说明
1. **大于 / 大于等于 / 等于 / 小于等于 / 小于**：比较左右两边的数值。
2. **字符包含**：左边这段文字里，是否包含右边这段文字。
3. **变量存在**：左边这个变量名当前是否已经存在。
4. **正则表达式**：左边的变量或值，是否匹配右边的正则。

### 参数解析
1. **判断**：最多 4 路，每一路可以单独开关。左值一般填变量名，右值可以是变量名或直接写的数字 / 文字。
2. **逻辑关系**：「且」表示 4 路全部成立才算成立；「或」表示有一路成立就算成立。
3. **分支指令**：「成立后」和「不成立后」两段都可以留空。
4. **流程控制**：无 / 循环-跳过本轮 / 循环-跳出 / 分支-跳出。成立、不成立可以分别设置，互不影响。
5. **结果保存**：勾选后，把这次判断的真值或假值写入指定变量，方便后面再用。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **执行顺序**：先写入结果变量，再执行对应分支里的指令，最后才做流程控制。所以分支里还能用到刚保存的结果。
2. **跳过与跳出**：
   - **循环-跳过本轮**：立刻结束本轮循环体剩下的指令，进入下一轮。
   - **循环-跳出**：离开当前这一层「循环」指令。如果当前并不在循环指令里，则会结束整条宏的外层循环。

## 17 文件读写

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/FileIO.png)  

### 功能说明
1. **读文件**：从 Excel 或文本文件读出内容，保存到变量或数组。
2. **写文件**：把一段内容或一个数组写入 Excel 或文本文件。

### 类型说明
1. **读取 Excel**
   - **单元格**：只读指定格子，结果写入变量。
   - **指定行**：从指定格子起，沿这一行往右读，直到连续空格较多时停止，结果写入数组。
   - **指定列**：从指定格子起，沿这一列往下读，规则同上，结果写入数组。
   - **指定区域-行 / 指定区域-列**：读取一块矩形区域。按行展开或按列展开，结果写入数组。
2. **写入 Excel**
   - **单元格**：写入指定格子。
   - **行号自增**：从指定格子起往下找第一个空格再写入，适合一行行追加记录。
   - **列号自增**：从指定格子起往右找第一个空格再写入。
   - **指定区域-行 / 指定区域-列**：把数组写进一块区域。一维数组会分别写成一行或一列。
3. **读取文本文件**
   - **读取全部内容**：整个文件读进一个变量。
   - **逐行读取**：从指定行号开始，把后面每一行读进数组。
   - **指定行**：只读某一行，写入变量。
4. **写入文本文件**
   - **覆盖写入**：清空原文件后再写入，原内容会丢。
   - **追加写入**：接在文件末尾继续写，不自动换行。
   - **追加写入-行**：先换一行，再在末尾写入。
   - **指定行**：改写某一行；文件行数不够时会先补空行。
   - **行号自增**：从指定行往下找第一个空行填进去；后面没有空行，就在末尾另起一行写入。

### 参数解析
1. **文件路径**：要读或写的目标文件。
2. **编码**：文本文件用的编码，默认 UTF-8。Excel 不受这项影响。
3. **表名或序号**：Excel 工作表的名称，或从 1 开始的序号。
4. **行列**：单元格位置或区域范围，可填变量。
5. **写入内容 / 数组**：写入时使用。写单个值用内容，写一块区域用数组。
6. **保存类型 / 名称**：读出的结果保存到变量还是数组。单元格、全文、指定行一般进变量，其它模式一般进数组。
7. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **Excel 速度**：写入时如果表格没有在 Excel 里打开，会慢很多。先打开再写会快。
2. **覆盖写入**：会清空原文件再写，请先确认路径没有填错。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`文件读写序号`，带备注时为 `文件读写序号_备注`
- 示例：`文件读写1`、`文件读写1_读配置`

3. **删除**：删掉整个数组。

3. **点击**：先按下，等待「点击时间」后再松开；可以连续重复多次。

### 参数解析
1. **窗口信息**：目标窗口，格式为 `标题⎖类名⎖进程名`，可点「编辑」用鼠标选取。
2. **类型**：按下 / 松开 / 点击。
3. **点击时间**：从按下到松开经过的时间，默认 `100` ms，受设置「点击时间浮动(%)」影响。
4. **点击次数**：连续点击多少次，默认 `1`。
5. **每次间隔**：两次点击之间的等待，默认 `100` ms，受设置「每次间隔浮动(%)」影响。仅选点击且次数大于 1 时生效。

1. **部分窗口无效**：很多游戏、部分程序不接收后台按键。有的窗口还必须管理员启动软件才有效。浏览器看起来按下了但页面没反应时，通常是该窗口不支持后台。
2. **不是连发**：选「按下 `a`」不会像长按键盘那样自动反复输入 `a`。
3. **配对松开**：用「按下」之后建议再配一条「松开」，否则目标窗口里可能卡键。组合键松开时按相反顺序抬起。
4. **点击耗时**：本条实际占用的时间 ≈（点击时间 + 每次间隔）× 点击次数 − 每次间隔。多数程序里，点击时间短于约 200ms 会被当成单击，长于约 250ms 会被当成长按。
5. **和前台按键**：本指令走窗口消息，不走宏设置里的 AHK / 罗技 / AHI，也不占用真实键盘。

### 快捷键
1. **F1**：按当前配置立刻模拟执行一次，和界面上的「模拟指令」相同。其它指令里的 F1 多半是取坐标，不要和这里搞混。
2. **键盘按键检测**：在输入框按下目标键后点「确定」，会自动勾选对应按键。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`后台按键序号`，带备注时为 `后台按键序号_备注`
- 示例：`后台按键1`、`后台按键1_回车`

## 23 窗口管理

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/WinManager.png)  

### 功能说明
1. **找窗口**：按标题、类名、进程名找到目标窗口。
2. **改窗口**：对找到的窗口做激活、缩放、移动、置顶、改标题、改透明度、鼠标穿透等操作。

### 类型说明
1. **激活窗口**：把后台或最小化的窗口带回前台并获得焦点。
2. **最大化 / 最小化 / 还原窗口**：调整窗口的显示状态。
3. **关闭窗口**：关掉这个窗口，但不会结束整个进程。进程可能仍留在托盘或后台。
4. **移动窗口**：把窗口左上角移到指定的屏幕坐标。
5. **调整大小**：设置窗口的宽度和高度。
6. **置顶 / 取消置顶**：窗口是否始终显示在其它窗口前面。
7. **修改标题**：改窗口标题栏上的文字。
8. **修改透明度**：0～100%，例如 `80%`。`0%` 完全透明，`100%` 完全不透明。
9. **开启 / 关闭鼠标穿透**：开启后，鼠标点击会穿过这个窗口，点到它后面的内容。

### 参数解析
1. **窗口信息**：按 `标题⎖类名⎖进程名` 匹配。三项都空则本条不执行。支持 `{变量名}` 替换。可点「编辑」用鼠标选取。
2. **坐标 X / Y**：仅「移动窗口」使用，可填变量。
3. **宽度 / 高度**：仅「调整大小」使用，可填变量。
4. **新标题**：仅「修改标题」使用，可填变量。
5. **透明度**：仅「修改透明度」使用，范围 `0%`～`100%`，可填变量。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **关窗口不是杀进程**：关了窗口之后，程序可能仍在托盘或后台运行。
2. **只操作可见窗口**：按标题等模糊匹配时，会解析成当前可见窗口的句柄，避免误操作到隐藏窗口。
3. **找不到窗口**：查找值填错、窗口已经关掉，或没有可见的匹配项时，本条没有效果。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`窗口管理序号`，带备注时为 `窗口管理序号_备注`
- 示例：`窗口管理1`、`窗口管理1_激活游戏`

## 24 按键检测

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/KeyCheck.png)  

### 功能说明
1. **读按键状态**：检测一个或多个键当前是不是按下的状态。
2. **写入变量**：符合检测条件时写入 `1`，否则写入 `0`。本指令自己不会按下任何键。

### 类型说明
1. **同时按下**：勾选的键必须全部处于按下，结果才是 `1`。
2. **有一个按下**：勾选的键里只要有一个处于按下，结果就是 `1`。

### 参数解析
1. **按键**：要检测哪些键，可以多选。
2. **检测模式**：同时按下 / 有一个按下。
3. **检测类型**：
   - **物理状态**：手指真实按着，或罗技等驱动模拟出来的按下，都算。AHK Send 这类普通模拟通常不算物理。
   - **逻辑状态**：物理按下，或者本软件宏指令模拟出来的按下，都算。
4. **结果变量**：用来存放 `1` 或 `0`。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **和按键指令**：本指令只读取状态，不会按下、也不会松开任何键。
2. **配合如果**：把结果变量交给「如果」去判断，就可以按「现在有没有按住」走不同分支。
3. **未选按键**：按键列表是空的时候，本条不会写入变量。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`按键检测序号`，带备注时为 `按键检测序号_备注`
- 示例：`按键检测1`、`按键检测1_是否按住Shift`

## 25 注释

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Remark.png)  

### 功能说明
1. **加说明**：在指令流里插入一段给人看的文字，方便以后阅读。
2. **不执行**：运行到本条时直接跳过，不消耗时间，也不会改任何状态。

### 参数解析
1. **注释内容**：说明文字，不能为空。文字太长时，指令串里只显示前面 20 个字，完整内容仍保存在这条指令里。

### 指令格式
- 格式：`注释序号_内容摘要`
- 示例：`注释1_下面开始吃药`

## 26 抓图

**指令界面**  
![配置界面](/RMT/Web/Images/MacroCMD/Shot.png)  

### 功能说明
1. **区域截图**：截取屏幕上的一块矩形，或某个窗口客户区里的一块矩形。
2. **给搜索用**：可以把保存后的图片完整路径写入变量，供后面的「搜索 / 搜索Pro」当作图片素材。

### 类型说明
1. **屏幕抓图**：按屏幕坐标截取，和哪个窗口在前无关。
2. **窗口抓图**：按窗口客户区坐标截取。窗口可以在后台。

### 参数解析
1. **抓图类型**：屏幕抓图 / 窗口抓图。
2. **窗口信息**：仅窗口抓图时使用，不能为空。可点「编辑」用鼠标选取。
3. **起始 / 终止坐标**：矩形的两个对角点，可填变量。起始坐标不能大于终止坐标。屏幕抓图填屏幕坐标，窗口抓图填该窗口客户区坐标。
4. **固定名称**：勾选后保存为 `名称.png`（名称不能为空）；不勾选则保存为 `序列号-时间戳.png`，每次文件名都不同。
5. **结果保存**：勾选后，把这次保存的图片完整路径写入变量。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **保存位置**：固定写到当前方案的 `Setting\<方案>\Images\TempShot`。安装目录没有写权限时，会改存到用户临时目录 `RMT_TempShot`。界面上不能自己指定保存路径。
2. **搜索引用**：搜索指令的图片路径填同一个变量名，就可以用刚抓下来的图去搜。
3. **覆盖**：勾选了固定名称时，重复抓图会覆盖同名文件。
4. **依赖 OpenCV**：本指令用 OpenCV 截图，插件不可用时会失败并提示。它和设置里的「截图方式」（微软 / RMT / SC）无关，那一项只给「RMT指令 · 截图」用。
5. **窗口抓图**：只截匹配到的第一个窗口，不会对多个窗口各截一张。

### 快捷键
1. **F1** / **左键框选截图范围**：框选后写入起始、终止坐标。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`抓图序号`，带备注时为 `抓图序号_备注`
- 示例：`抓图1`、`抓图1_当前血条`

## 27 时间

### 功能说明
1. **指定时刻等待**：暂停执行，直到系统时间到达指定时刻（如 `14:30:00`）或经过指定相对时长（秒/分钟/小时/天）。支持超时中断与轮询间隔。
2. **时间区间判断**：检查当前时间是否位于允许的时刻区间（如 `09:00:00` ~ `18:00:00`）及指定星期几。不满足时可选择跳过、等待或停止宏。
3. **获取时间变量**：解析来源时间（或当前时间）并以标准时间格式（`yyyy-MM-dd HH:mm:ss`）写入目标时间变量。
4. **获取时间字符串**：根据指定格式化模板（如 `yyyy-MM-dd HH:mm:ss`、`UnixTimestamp`、`E`、`EEEE` 等）格式化时间，并写入字符串变量。
5. **时间计算**：计算两个时间源之间的差值（耗时统计），或对基准时间进行增加/减少偏移。

### 类型说明
1. **指定时刻等待**：支持具体时间字符串、相对时长（秒/分钟/小时/天）、时间变量值。到达目标时间后继续执行下一条指令。
2. **时间区间判断**：支持设置开始/结束时间、允许星期（1~7），以及不满足时的动作（跳过/等待/停止）。
3. **获取时间变量**：生成标准格式的时间变量，供后续时间计算或等待指令使用。
4. **获取时间字符串**：支持常用格式化模板：
   - `yyyy-MM-dd HH:mm:ss` / `yyyyMMdd` / `HH:mm:ss`：常规年月日时分秒。
   - `UnixTimestamp`：10位 Unix 秒级时间戳。
   - `E`：星期几数字（`1`~`7`，`1` 代表周一）。
   - `EEEE`：星期全称（如 `星期一` / `Monday`）。
   - `EEE`：星期简称（如 `周一` / `Mon`）。
5. **时间计算**：支持两个时间差值计算（输出单位可选秒、毫秒、分钟、小时、天、HH:mm:ss）以及时间偏移计算。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`时间序号`，带备注时为 `时间序号_备注`
- 示例：`时间1`、`时间1_整点开抢`
