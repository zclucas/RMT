# 🚀 指令手册 - RMT（若梦兔）

本页按宏编辑器左侧的默认分类与指令顺序排列：键鼠/手柄 → 搜索/识图 → 输入/输出 → 变量/数据 → 文件 → 流程 → 调控 → 其他。个人收藏区不影响本手册顺序。

各节名称与界面一致，介绍指令用途、类型、参数和执行注意事项。带序列号的指令将参数保存在配置中；备注只用于辨认。部分旧版内联指令格式仍可兼容，新增指令建议通过编辑器配置。

## 1 按键

所属分类：键鼠/手柄

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Key.png)

### 功能说明
1. **按下 / 松开 / 点击**：对界面里勾选的那些键，执行对应动作。
2. **组合键**：可以同时勾选多个键。执行时按勾选顺序一起按下；松开时按相反顺序抬起。

### 类型说明
1. **按下**：按下指定按键后立刻继续下一条（瞬发，本条不消耗时间）。
2. **松开**：松开指定按键后立刻继续下一条（瞬发）。
3. **点击**：先按下，等待「点击时间」后再松开；可以连续重复多次。

### 参数解析
1. **类型**：按下 / 松开 / 点击。只有选「点击」时，下面三项才生效。
2. **点击时间**：从按下到松开经过的时间（毫秒）。省略时默认 `100`。
3. **点击次数**：连续点击多少次。省略时默认 `1`。
4. **每次间隔**：松开之后、下一次再按下之前的等待（毫秒）。省略时默认 `0`。只在点击次数大于 1 时有意义。

### 特别说明
1. **瞬发**：按下、松开执行完立刻走下一条，本条本身不等待。
2. **不是连发**：选「按下 `a`」只是把 `a` 按住，不会像物理键盘长按那样自动反复输入 `a`。系统长按时，其实是在不断松开再按下；本指令不会这么做。
3. **配对松开**：用「按下」之后，建议后面再配一条「松开」。只按不松就再按一次，后续按下可能无效（卡键）。
4. **点击与长按**：这不是本指令里的两种类型，而是目标程序怎么理解这次按住。多数程序里，点击时间短于约 200ms 会被当成单击，长于约 250ms 会被当成长按；200～250ms 介于两者之间，表现因软件而异。
5. **点击耗时**：本条实际占用的时间 ≈（点击时间 + 每次间隔）× 点击次数 − 每次间隔。最后一次松开后不会再等「每次间隔」。
6. **浮动**：点击时间受设置「点击时间浮动(%)」影响；每次间隔受「每次间隔浮动(%)」影响。按下、松开是瞬发，不受点击时间浮动影响。这两项也不是「间隔指令浮动」。
7. **结束松键**：这里说的是宏的**触发类型**（按下 / 松开 / 双击 / 长按 / 开关），不是本指令的按下 / 松开 / 点击。触发类型为按下、松开、双击、长按时，宏**正常跑完不会**自动松开仍按住的键。只有被终止，或触发类型是**开关**并结束时，才会兜底松开。因此「只按下不松开」在开关宏里看起来没事，换其它触发类型就容易卡键。
8. **宏设置 · 按键类型**：本指令不选择模拟方式，发送走的是该条宏「宏设置」里的按键类型。
   - **AHK Send**：通用，适合办公和多数游戏（管理员权限可让更多游戏有效）
   - **keybd_event**：系统接口，适合老软件或游戏（需管理员）
   - **罗技**：走罗技驱动（需管理员，G HUB 需为 2022.2.1154 及以前版本）
   - **AHI**：走 Interception 驱动（需管理员，并安装 Interception）
   记事本能触发、游戏里无效时，优先勾选「管理员启动」，再改这条宏的按键类型，而不是改本指令的点击时间。
9. **按下时按下**：宏已经把某键按住，又执行一次「按下」时，由设置「按下时按下」决定：自动松开（默认，先松再按）、忽略重复按下、允许重复按下（罗技模式可能卡死）。
10. **自触发**：keybd_event、罗技、AHI 模拟出的键可以作为宏的触发键。触发键不要和本指令输出的键相同，否则会自己触发自己形成死循环。
11. **点击时间建议**：建议不低于 **100ms**，低于 **30ms** 时后续指令容易丢失。不追求极限速度时，点击后再加一条间隔更稳。
12. **手柄**：键盘鼠标用本指令。虚拟手柄请用「手柄」指令。

### 键盘按键检测
1. 点击界面上的输入框。
2. 按下要模拟的目标按键或组合键。
3. 点击「确定」，软件会自动勾选对应按键，不必在列表里一个个找。

### 指令格式
- 按下：`按键_按键名_按下`
- 松开：`按键_按键名_松开`
- 点击：`按键_按键名_点击_点击时间_点击次数_每次间隔`
- 多键：键名之间用 `⎖` 连接，例如 `按键_Ctrl⎖a_点击_100`
- 示例：`按键_a_按下`、`按键_a_点击_100`、`按键_a_点击_100_10_200`

## 2 后台按键

所属分类：键鼠/手柄

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/BGKey.png)

### 功能说明
1. **后台按键**：向指定窗口发送按键消息，不会占用真实键盘，其它窗口也收不到这些键。
2. **可组合**：可以同时勾选多个键，按组合键发送。

### 类型说明
1. **按下**：向目标窗口发送按下，然后立刻继续下一条（瞬发）。
2. **松开**：向目标窗口发送松开，然后立刻继续下一条（瞬发）。
3. **点击**：先按下，等待「点击时间」后再松开；可以连续重复多次。

### 参数解析
1. **窗口信息**：目标窗口，格式为 `标题⎖类名⎖进程名`，可点「编辑」用鼠标选取。
2. **类型**：按下 / 松开 / 点击。
3. **点击时间**：从按下到松开经过的时间，默认 `100` ms，受设置「点击时间浮动(%)」影响。
4. **点击次数**：连续点击多少次，默认 `1`。
5. **每次间隔**：两次点击之间的等待，默认 `100` ms，受设置「每次间隔浮动(%)」影响。仅选点击且次数大于 1 时生效。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **部分窗口无效**：很多游戏、部分程序不接收后台按键。有的窗口还必须管理员启动软件才有效。浏览器看起来按下了但页面没反应时，通常是该窗口不支持后台。
2. **不是连发**：选「按下 `a`」不会像长按键盘那样自动反复输入 `a`。
3. **配对松开**：用「按下」之后建议再配一条「松开」，否则目标窗口里可能卡键。组合键松开时按相反顺序抬起。
4. **点击耗时**：本条实际占用的时间 ≈（点击时间 + 每次间隔）× 点击次数 − 每次间隔。多数程序里，点击时间短于约 200ms 会被当成单击，长于约 250ms 会被当成长按。
5. **和前台按键**：本指令走窗口消息，不走宏设置里的 AHK / 罗技 / AHI，也不占用真实键盘。

### 快捷键
1. **F1**：按当前配置立刻模拟执行一次，和界面上的「模拟指令」相同。其它指令里的 F1 多半是取坐标，不要和这里搞混。
2. **键盘按键检测**：在输入框按下目标键后点「确定」，会自动勾选对应按键。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`后台按键序号`，带备注时为 `后台按键序号_备注`
- 示例：`后台按键1`、`后台按键1_回车`

## 3 后台鼠标

所属分类：键鼠/手柄

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Mouse.png)

### 功能说明
1. **后台点击**：向指定窗口发送鼠标消息，真实光标不会移过去。
2. **可滚轮**：除了左 / 中 / 右键，也可以发垂直或水平滚轮消息。

### 类型说明
1. **点击 / 双击 / 按下 / 松开**：对左、中、右键执行对应动作。选了滚轮时，这四项不会出现。
2. **滚轮**：按垂直 / 水平滚动量让目标窗口滚动，不会带动真实滚轮。

### 参数解析
1. **窗口信息**：按 `标题⎖类名⎖进程名` 匹配，可点「编辑」用鼠标选取。同时命中多个窗口时，会对每个窗口各发一次。
2. **鼠标按键**：左键、中键、右键、滚轮。
3. **操作类型**：点击、双击、按下、松开。选滚轮时没有这项。
4. **窗口坐标 X / Y**：相对该窗口客户区左上角，不是屏幕坐标。可填变量。受设置「坐标 X / Y 浮动」影响。
5. **垂直滚动 / 水平滚动**：仅滚轮时出现。垂直滚动量不是 0 时，只滚垂直，水平那一项不会再生效。
6. **点击时间**：仅点击、双击时出现，默认 `50` ms，表示按下到松开隔多久。
7. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **不是所有窗口都有效**：很多游戏、部分程序不接收后台鼠标消息。浏览器看起来点了但页面没反应时，通常是该窗口不支持后台，不是坐标填错。
2. **管理员**：部分窗口必须用管理员权限启动软件才有效。
3. **和前台移动 / 按键**：本指令走窗口消息，不移动真实光标，也不走宏设置里的 AHK / 罗技 / AHI。
4. **坐标变量**：X 或 Y 所用的变量取不到时，本条整条不执行。

### 快捷键
1. **F1**：同时填入鼠标下窗口信息（`标题⎖类名⎖进程名`）和窗口坐标。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`后台鼠标序号`，带备注时为 `后台鼠标序号_备注`
- 示例：`后台鼠标1`、`后台鼠标1_点确定`

## 4 移动

所属分类：键鼠/手柄

**指令界面**
![配置界面](/RMT/Web/Images/MacroCMD/Move.png)

### 功能说明
按固定坐标移动鼠标指针。可选择绝对移动或相对移动；需要变量坐标、移动后点击、窗口坐标或拟真轨迹时，使用「移动Pro」。游戏视角位移使用「增量移动」。

### 类型说明
1. **绝对移动**：填写目标点的屏幕坐标。
2. **相对移动**：填写相对于当前指针的偏移量。例如当前位于 `(100,100)`，填写 `10,0`，目标为 `(110,100)`。

### 参数解析
1. **坐标 X / Y**：填写整数；绝对移动时为目标点，相对移动时为偏移量。
2. **移动速度**：0～100，越大越快，100 为瞬间到达，默认 90。
3. **移动方式**：绝对移动或相对移动。

### 特别说明
- 移动方式跟随宏设置中的按键类型，支持普通、罗技或 AHI 等发送方式。
- 本指令只移动，不点击；坐标受设置中的坐标浮动影响。
- 兼容名称「鼠标移动」，当前界面名称为「移动」。

### 快捷键
- **F1**：使用当前鼠标坐标作为目标点。
- **标题栏预览按钮**：切换指令预览，在屏幕上持续显示主题配色的路径箭头；再次点击或关闭编辑器后关闭。相对移动按当前指针加偏移显示。预览不会执行鼠标动作。

### 指令格式
- 当前编辑器将参数保存到配置中，宏中写 `移动序号` 或 `移动序号_备注`。
- 示例：`移动1`、`移动1_800 600`。
- 兼容旧内联格式：`移动_坐标X_坐标Y_移动速度_移动方式`，移动方式 `0` 表示绝对、`1` 表示相对。

## 5 移动Pro

所属分类：键鼠/手柄

**指令界面**
![配置界面](/RMT/Web/Images/MacroCMD/MovePro.png)

### 功能说明
按坐标移动鼠标，并可在到达后单击、双击或按住左键拖拽。支持变量坐标、窗口坐标基准和拟真轨迹。

### 类型说明
1. **屏幕基准**：绝对移动时按屏幕坐标定位；相对移动时以当前指针位置为起点。
2. **窗口基准**：按所选窗口左上角加偏移计算目标点，使用绝对移动。

### 参数解析
1. **坐标基准**：屏幕或窗口。窗口基准需要填写窗口信息，可通过编辑按钮选择目标窗口。
2. **坐标 X / Y**：可填数值或变量；含义由坐标基准、移动方式和鼠标动作决定。绝对拖拽时显示为「起始点」。
3. **终止点**：仅在「鼠标动作 = 拖拽 + 绝对移动」时出现；填写拖拽结束的位置，同样支持变量。相对拖拽不需要填写。
4. **移动方式**：绝对移动或相对移动；窗口基准下固定使用绝对移动。
5. **鼠标动作**：移动、移动后单击、移动后双击、拖拽。
   1. **拖拽**：按住左键拖动再松开。绝对移动时从 X / Y 拖到「终止点」；   相对移动时从当前指针按 X / Y 偏移拖动。
6. **移动速度**：0～100，越大越快，100 为瞬间到达。
7. **拟真轨迹**：启用后按更接近人手的轨迹移动。
8. **备注**：帮助辨认指令，不改变执行行为。

### 特别说明
- 本指令移动真实鼠标指针。窗口基准用于定位，后台点击请使用「后台鼠标」。
- 移动、点击以及拖拽的按下与松开，都跟随宏设置中的按键类型，支持普通、罗技或 AHI 等发送方式。
- 拟真轨迹启用后鼠标动作锁定为「移动」，且「移动方式」「鼠标动作」不可再调整；取消勾选后恢复可选。罗技或 AHI 按键类型下按普通轨迹移动，不使用拟真轨迹。
- 坐标受设置中的坐标浮动影响；窗口基准下找不到目标窗口、或坐标为尚未取到值的变量时，本条指令不执行。
- 拖拽结束后会自动松开左键；中途报错或中断时同样会松开，避免左键保持按下。
- 相对移动完成后会短暂延时再点击，便于目标程序识别指针位置。
- 旧版「移动Pro」的游戏视角功能已单独放入「增量移动」，当前界面不再通过屏幕规格配置多套坐标；旧配置仍按原来的相对位移方式兼容执行。

### 快捷键
- **F1**：取当前鼠标坐标。相对移动下按已填坐标折算成偏移量；拖拽时先聚焦起始或终止坐标框，再取对应点位。
- **标题栏预览按钮**：切换指令预览，在屏幕上持续显示主题配色的路径箭头；再次点击或关闭编辑器后关闭。以按钮点亮时的指针位置作为起点，拖拽显示起点到终止点，窗口基准按目标窗口左上角对齐。坐标是变量时无法预览，会提示先换成数值；窗口基准下未找到目标窗口也会提示。预览只画线，不会真的移动鼠标。

### 指令格式
- 参数保存在配置中，宏中写序列号。
- 格式：`移动Pro序号` 或 `移动Pro序号_备注`
- 示例：`移动Pro1`、`移动Pro1_点按钮`
- 旧名称 `鼠标移动Pro序号` 仍可识别执行，建议改用新名称。

## 6 增量移动

所属分类：键鼠/手柄

### 功能说明
发送相对鼠标位移，适合第一／第三人称游戏转动视角，也可重复发送同一偏移。该功能从旧版「移动Pro」的游戏视角模式中独立出来。

### 参数解析
1. **X / Y 偏移**：每次发送的水平与垂直位移；正负值控制方向，可选择变量或填写数值。
2. **移动次数**：重复发送位移的次数。
3. **每次间隔**：两次位移之间等待的毫秒数。
4. **备注**：便于辨认这条指令。

### 特别说明
- 使用相对位移接口，不把 X / Y 当作屏幕上的目标点；不附带鼠标点击或拟真轨迹。
- 游戏中的实际转动角度受游戏灵敏度和输入处理影响。先用较小位移与次数试运行。
- 此类游戏视角位移固定走 `mouse_event`，不随宏的罗技或 AHI 按键类型切换。

### 快捷键
- **标题栏预览按钮**：切换指令预览，以圆点标出每一步的落点并显示整体路径箭头；修改参数后自动刷新，再次点击或关闭编辑器后关闭。位移与次数需填数值，预览不会执行鼠标动作。

### 指令格式
- 参数保存在配置中，宏中写 `增量移动序号` 或 `增量移动序号_备注`。
- 示例：`增量移动1`、`增量移动1_向右转`

## 7 手柄

所属分类：键鼠/手柄

### 功能说明
1. **按钮 / 方向键**：在手柄图上点击按键，执行按下、松开或点击。可组合多个按键。
2. **摇杆 / 扳机轴**：点击摇杆盘或扳机轴条，设置轴值并保持，直到下一条同轴指令覆盖（轴值 0 即回中）。

### 类型说明
1. **按下 / 松开 / 点击**：与「按键」指令相同，仅作用于手柄按钮和方向键。
2. **轴值**：摇杆 LX/LY、RX/RY 各轴范围 `-100 ~ 100`（0 为中心）。真实手柄两轴独立饱和，合成向量按圆形限位（半径约 125），因此可以出现 `LX:100_LY:67`，不会出现 `LX:100_LY:100`。扳机 LT/RT 范围 `0 ~ 100`。

### 特别说明
1. 使用前需要安装软件 Joy 目录下的 **ViGEmBus.exe**，否则手柄键发不出去。
2. 设置里的**宏手柄类型**（Xbox / DS4）决定游戏实际收到哪种虚拟手柄；**手柄映射**只改界面上按键名称怎么显示（例如 A 还是 ×），不改实际输出。
3. 手柄输出走 ViGEm 虚拟手柄，不走 AHK / 罗技 / AHI 键盘通道。
4. 旧宏里写在「按键」指令中的手柄键仍可执行；重新编辑后会保存为「手柄」指令。
5. 打开编辑器后，按真实手柄按键或推动摇杆会自动选中并写入对应值。

### 指令格式
- 按钮：`手柄_A_点击_点击时间_点击次数_每次间隔`
- 组合：`手柄_A+B_按下`
- 方向：`手柄_上_按下`
- 摇杆：`手柄_LX:80`、`手柄_LX:80_LY:20`
- 扳机：`手柄_LT:50`
- 示例：`手柄_A_点击_100`、`手柄_LB_按下`、`手柄_RT:100`

## 10 搜索

所属分类：搜索/识图

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Search.png)

### 功能说明
1. **屏幕搜索**：在屏幕指定范围内查找图片、颜色或文本。
2. **分支执行**：找到或没找到时，可以分别执行一段指令（不填则只搜、不分支）。
3. **简化配置**：本指令是「搜索Pro」的简化版。默认只搜 1 次、相似度约 90。窗口搜索、改相似度、多次重试、把结果或坐标写入变量等，见「搜索Pro」。

### 类型说明
1. **屏幕图片**：在范围内匹配目标图片。图片可以选本地文件，或用 F2 当场截图。
2. **屏幕颜色**：在范围内查找指定颜色。颜色可以手填 HEX，或用 F3 取当前鼠标位置的颜色。
3. **屏幕文本**：在范围内匹配文字，支持正则表达式。

### 参数解析
1. **搜索范围**：从起始坐标到终止坐标围成的矩形。起始坐标不能大于终止坐标；做图片搜索时，范围不能小于图片本身。坐标可填整数或变量。
2. **搜索目标**：图片选本地文件或截图；颜色填 HEX 或用 F3 取色；文本直接输入（支持正则，也可引用变量）。
3. **鼠标动作**：找到后要对鼠标做什么：无动作 / 移动到目标 / 移动到目标并点击 1 次 / 移动到目标并点击 2 次。
4. **分支指令**：「找到后」和「未找到后」两段指令都可以留空。留空表示搜完就继续后面的主流程。
5. **备注**：写在指令串序列号后面，只用于辨认，不影响搜索。

### 特别说明
1. **搜索不是识别**：源素材要和屏幕上的目标基本一致才能搜到。它比的是像素是否像，不是「看懂画面」。
2. **分支前加间隔**：找到后会先做鼠标动作，再执行「找到后」分支。目标程序反应慢时，分支开头需要加间隔，避免点完立刻做下一步。
3. **文本支持正则**：搜索文本可按正则匹配。
4. **范围与素材**：范围越小、图片越小，速度越快。截图只截特征部分，不要带会变化的背景（推荐 32×32 或 48×48）。
5. **dll 加载失败**：图片或文本搜索提示 dll 失败时，请看「问题及应对措施」，或到工具页做文件校验补齐插件。
6. **图片丢失**：提示图片不存在时，若软件目录变过，到配置管理做「配置校准」。
7. **和搜索Pro**：两者用同一套执行引擎。本指令默认搜 1 次、相似度约 90，不能做窗口搜索、不能无限重试、不能把成败或坐标写入变量；需要这些时用搜索Pro。

### 快捷键
1. **F1**：开启框选范围（左键松开后关闭）。
2. **F2**：截图作为搜索图片素材，并根据图片位置、大小自动选取搜索范围。
3. **F3**：选取当前鼠标位置颜色值作为颜色搜索的素材。
4. **定位取色器**：更精细地确定坐标、拾取颜色。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`搜索序号`，带备注时为 `搜索序号_备注`
- 示例：`搜索1`、`搜索1_找血条`

## 11 搜索Pro

所属分类：搜索/识图

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/SearchPro.png)

### 功能说明
1. **屏幕搜索**：在屏幕指定范围内查找图片、颜色或文本，并按找到 / 未找到执行分支。
2. **窗口搜索**：在符合窗口信息的窗口里搜索。目标窗口可以在后台或最小化，不必露在最前面。
3. **结果保存**：可以把成功 / 失败写入变量；找到时也可以把目标中心点坐标写入变量。
4. **完整配置**：和「搜索」用同一套执行引擎。搜索是简化版；本指令可以改相似度、次数、间隔、识图模型和窗口信息，并支持图片自适应匹配。

### 类型说明
1. **屏幕图片 / 屏幕颜色 / 屏幕文本**：在屏幕坐标范围内搜索。
2. **窗口图片 / 窗口颜色 / 窗口文本**：在指定窗口内部搜索，可在后台或最小化时使用。窗口搜索的范围需要自己框选，不会按屏幕自动对应。

### 参数解析
1. **图片识别自适应**：在「设置 → 系统 → 通用」的「图片识别模型」下方统一开启，对所有使用 OpenCV 的图片搜索生效，尝试匹配因分辨率或 DPI 缩放变化而改变大小的目标。默认关闭；颜色、文本搜索及 RMT 识图不使用此选项。换设备后仍需检查搜索范围是否覆盖目标，必要时重新截图和框选。
2. **搜索范围**：从起始坐标到终止坐标围成的矩形。起始不能大于终止；做图片搜索时，范围不能小于图片。坐标可填整数或变量。
3. **搜索目标**：图片选本地文件或截图（路径也可引用变量）；颜色填 HEX 或用 F3 取色；文本可输入内容（支持正则）或引用变量。
4. **相似度**：值越大匹配越严格，越不容易误搜到别的东西。只对图片、颜色生效，文本搜索不用这项。
5. **搜索次数**：没找到就再试，直到找到或次数用尽。也可以选「无限」，一直等到出现。
6. **每次间隔**：两次搜索之间的等待。只在次数大于 1 或选了无限时生效。受设置「每次间隔浮动(%)」影响，不是「间隔指令浮动」。
7. **鼠标动作**：
   - 屏幕：无动作 / 移动到目标 / 移动到目标并点击（可设移动速度、点击次数；速度 100 为瞬间到达）
   - 窗口：无动作 / 后台鼠标到目标点击 / 后台鼠标到目标双击（不移动真实光标）
8. **窗口信息**：窗口搜索时必填。可以填窗口句柄，或按 `标题⎖类名⎖进程名` 三项来匹配（某一项可以留空）。同时匹配到多个窗口时，鼠标动作会对每个匹配窗口各做一次。
9. **图片识别模型**：OpenCV（推荐，仅 64 位）：默认按灰度匹配，相似度不再自动切换颜色模式。搜索 Pro 和搜索 Combo 的图片目标可在相似度右侧勾选「颜色匹配」，默认不勾选；勾选后会比较图像颜色，自适应缩放时也会校对颜色。RMT 识图走 AHK `ImageSearch`，不显示该选项。
10. **文本识别模型**：中文模型识别中文 / 英文 / 数字（字库大、稍慢，`Plugins\RapidOcr\ch_models\ppocr_keys_v1.txt`）；英文模型识别英文 / 数字（更快，`Plugins\RapidOcr\en_models\ppocr_keys_v1.txt`）。缺字请加到对应字库文件顶部。
11. **分支指令**：「找到后」和「未找到后」两段指令都可以留空。
12. **结果保存**：勾选后，找到写入真值、没找到写入假值。
13. **目标点保存**：勾选后，只在找到时把目标中心点的屏幕坐标写入变量；没找到不改原值。
14. **备注**：写在指令串序列号后面，只用于辨认，不影响搜索。

### 特别说明
1. **搜索不是识别**：源素材要和目标基本一致才能搜到。它比的是像素是否像，不是「看懂画面」。
2. **无限次数**：会一直搜到找到为止，之后只走「找到」分支，「未找到」分支不会触发。暂停、终止可以打断。
3. **耗时**：本条实际占用的时间 ≈（单次检索时间 + 每次间隔）× 实际搜索次数 − 每次间隔。最后一次搜完后不会再等「每次间隔」。
4. **分支前加间隔**：找到后先做鼠标动作，再执行「找到后」分支。目标程序反应慢时，分支开头需要加间隔。
5. **范围与素材**：范围越小、图片越小，速度越快。图片推荐只截特征，大约 32×32，不要带会变的背景。文本推荐多字一起搜，单字符容易不准。
6. **截图后改大小**：用 SC 截图后如果又改了图片大小，搜索范围需要重新框选，否则范围和素材对不上。
7. **dll 加载失败**：请看「问题及应对措施」，或到工具页做文件校验。
8. **图片丢失**：软件目录变过时，到配置管理做「配置校准」。
9. **和搜索**：本指令参数更多。只做一次屏幕搜索、不用把结果写入变量时，用「搜索」即可。

### 快捷键
1. **F1**：开启框选范围（左键松开后关闭）。
2. **F2**：截图作为搜索图片素材，并根据图片位置、大小自动选取搜索范围。
3. **F3**：选取当前鼠标位置颜色值作为颜色搜索的素材。
4. **定位取色器**：更精细地确定坐标、拾取颜色。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`搜索Pro序号`，带备注时为 `搜索Pro序号_备注`
- 示例：`搜索Pro1`、`搜索Pro1_找血条`

## 12 搜索Combo

所属分类：搜索/识图

### 功能说明
在同一条指令中配置多个搜索目标，按「满足个数」判断本轮搜索是否成功。各目标可分别使用图片、颜色或文本搜索，也可分别选择屏幕或窗口搜索。

### 参数解析
1. **目标列表**：添加、删除并选择当前编辑的目标。每个目标独立设置搜索类型、窗口信息、范围、目标内容、相似度和识别模型。
2. **满足个数**：选择「所有」表示全部目标都要找到；填写正整数表示找到至少这么多个目标即可。统计的是满足条件的目标条目数。
3. **搜索次数 / 每次间隔**：设置最多尝试的轮数与轮次之间的等待；选择无限时持续尝试，直到满足或宏被终止。
4. **鼠标动作**：整体条件满足后，对本轮已收集的找到位置执行所选动作；屏幕目标和窗口目标使用各自对应的动作方式。
5. **结果保存 / 目标点保存**：将成功或失败的值、找到位置的坐标写入指定变量。
6. **找到后 / 未找到后**：整体成功或有限次数用尽仍未成功时执行对应分支，两段都可留空。

### 特别说明
- 每轮按目标列表顺序搜索，达到满足个数后就结束本轮，不保证继续搜索后面的目标。
- 整体条件满足后，「找到后」分支只执行一次；有多个位置时，同一组坐标变量会依次写入，最终保留最后写入的位置。
- 框选范围、截图和取色作用于当前选中的目标。切换目标后检查对应参数，避免把某个目标的范围填到另一个目标上。
- 只查一个目标时优先使用「搜索」或「搜索Pro」。旧版多目标搜索Pro可在本编辑器中继续编辑。

### 快捷键
- **F1**：框选当前目标的搜索范围。
- **F2**：为当前目标截图。
- **F3**：取色。

### 指令格式
- 参数保存在配置中，宏中写 `搜索Combo序号` 或 `搜索Combo序号_备注`。
- 示例：`搜索Combo1`、`搜索Combo1_检查多个按钮`

## 13 输入

所属分类：输入/输出

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Input.png)

### 功能说明
1. **写入变量**：弹出输入框或真 / 假按钮，把用户的选择保存到变量，供后面的指令使用。
2. **控制流程**：用按钮让宏在这里停一下等人操作，确认后继续，或取消并终止。

### 类型说明
1. **弹窗**：弹出输入框，把用户输入的内容写入变量。适合问数量、名字这类需要打字的场合。
2. **状态**：弹出真 / 假两个按钮。选真写入 `1`，选假写入 `0`。适合让人做一次是否判断。
3. **继续**：只弹出一个继续按钮，点了之后才执行后面的指令。适合「确认后再往下走」。
4. **继续&取消**：弹出继续和取消。点继续则往下执行；点取消则按「取消时」的规则终止宏。

### 参数解析
1. **类型**：弹窗 / 状态 / 继续 / 继续&取消。
2. **交互时**：窗口开着时，其它正在跑的宏怎么办。无论选哪一项，本条都会等到窗口关掉才继续后面的指令。选「暂停所有宏」时，其它宏也会先停住，关掉窗口后再恢复。
3. **取消时**：仅「继续&取消」使用。点取消时，是只终止当前这条宏，还是终止所有正在跑的宏。
4. **保存变量**：仅「弹窗」「状态」使用，用来存放输入内容或 `1` / `0`。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **快捷键**：回车视为真值或继续；Esc 视为假值或取消。
2. **Enter 不误触**：输入弹窗打开期间，Enter 触发键会被暂时禁用，避免回车把别的宏触发了。
3. **关掉才继续**：窗口还开着时，本条后面的指令不会执行。关掉窗口后才会继续。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`输入序号`，带备注时为 `输入序号_备注`
- 示例：`输入1`、`输入1_问数量`

   - **当前鼠标颜色**：如 `EEFF44`

   - **窗口宽度 / 高度**：当前鼠标所在窗口的宽、高

## 16 变量提取

所属分类：变量/数据

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Extract.png)

### 功能说明
1. **抽取文本**：先从屏幕、剪贴板或窗口得到一段文字，再按模板从中取出数字或文字，写入变量。
2. **可重试**：识别失败或模板对不上时，可以按次数、间隔再试。

### 类型说明
1. **屏幕**：对屏幕上的一块矩形做 OCR，再按模板提取。
2. **剪切板**：不对屏幕识字，直接对剪贴板里已有的文本提取。
3. **窗口**：对指定窗口客户区做 OCR 后再提取。窗口可以在后台，不必露在最前面。

### 参数解析
1. **提取源**：屏幕 / 剪切板 / 窗口。
2. **提取文本**：提取模板。留空则把识别到的全部文本写入第一个开启的变量。`&x` 占一个数字，`&c` 占一段文本；模板里的 `{变量名}` 会先替换成变量值，再拿去匹配。
3. **搜索次数 / 每次间隔**：没提取成功就再试，直到成功或次数用尽。间隔受「每次间隔浮动」影响。
4. **窗口信息**：仅窗口提取时使用。可以填句柄，或按 `标题⎖类名⎖进程名` 匹配。同时匹配到多个窗口时，会对每个窗口各处理一次。
5. **识别模型**：中文模型识别中文 / 英文 / 数字（字库大、稍慢）；英文模型识别英文 / 数字（更快）。字库分别在 `Plugins\RapidOcr\ch_models\ppocr_keys_v1.txt`、`en_models\ppocr_keys_v1.txt`。缺字请加到对应文件顶部。
6. **提取范围**：仅屏幕提取时使用的矩形。可用 F1 框选。
7. **结果保存**：最多 6 路。可勾选「变量存在忽略」（已有则不改）；没勾选的路不会写入。
8. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **可能失败**：OCR 看错字，或识别结果对不上模板时，这次提取会失败，不会写入提取值。
2. **失败时怎么写变量**：
   - 变量还不存在，且这次失败：创建该变量，值为 `0`
   - 变量已经存在，且这次失败：不改原来的值
   - 提取成功：写入这次提取到的值
3. **模板示例**：
   - `&x`：取出第一个数字
   - `&c`：取出第一段文本
   - `HP：&x`：从 `HP：3,000` 取出 `3000`
   - `坐标(&x,&x)`：从 `坐标(10.5,8.6)` 取出两个数
   - `{Title}：&x`：若变量 `Title` 当前是 `血量`，则去匹配 `血量：20.5` 并取值
4. **无限次数**：会一直抽到成功为止；暂停、终止可以打断。

### 快捷键
1. **F1**：左键框选提取范围。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`变量提取序号`，带备注时为 `变量提取序号_备注`
- 示例：`变量提取1`、`变量提取1_读血量`

### 特别说明
1. **下标从 1**：第 1 个元素的下标是 1，不是 0。子索引填 `0` 表示「整个数组」，不是「第 0 个元素」。
2. **输出展开**：输出指令里用 `{ε数组名}` 可以把数组内容展开成文本。
3. **全局**：数组和变量一样是全局的，所有宏共用同一个名字。

### 功能说明
1. **插入间隔**：插在两条指令中间。执行到本条时先等待，再继续后面的指令。
2. **循环间隔**：把本条放在整段宏的最后。外层每一轮指令都跑完后，会先等这段时间，再开始下一轮。它不会改变宏配置里的「循环次数」。

1. **整数**：等待时长，单位是毫秒。例如 `3000` 表示 3 秒，`0` 等于不等待。
2. **变量**：读取变量的当前值，当作等待时长（同样是毫秒）。

### 特别说明
1. **间隔指令浮动**：设置页「间隔指令浮动(%)」只作用于本指令。未写正负号时上下都浮动，例如间隔 `3000`、浮动 `10`，实际约 `2700～3300` ms。按键连点、搜索多次之间的等待走的是「每次间隔浮动」，与本项无关。
2. **循环间隔**：宏要循环几遍，由这条宏配置上的「循环次数」决定，本指令改不了这个数字。放在末尾只是让每一轮跑完后再等待，再进入下一轮；随机间隔每轮会重新抽取。

### 指令格式
- 固定：`间隔_时间A_备注`
- 随机：`间隔_时间A~时间B_备注`
- 示例：`间隔_500`、`间隔_500_等待`、`间隔_500~1000`、`间隔_500~1000_随机等待`

## 23 循环

所属分类：流程

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Loop.png)

### 功能说明
1. **重复执行**：按指定次数，反复执行循环体里的那一段指令。
2. **条件控制**：可以在每一轮开始时先判断条件，再决定本轮要不要跑、或要不要离开循环。

### 类型说明
1. **无**：不设条件，只按「循环次数」执行。次数到了就结束。
2. **继续条件**：每一轮先判断。条件成立才执行循环体；不成立则离开循环。
3. **退出条件**：每一轮先判断。条件成立则立刻离开循环，不再执行本轮循环体。

### 参数解析
1. **循环次数**：循环体最多执行多少次。这是本指令自己的次数，不是宏配置上那个「循环次数」。
2. **循环条件**：无 / 继续条件 / 退出条件。可添加任意数量，比较方式和「如果」相同。
3. **逻辑关系**：多路条件之间用「且」（全部成立才算成立）或「或」（有一路成立就算成立）。
4. **循环体**：每一轮要跑的指令组合。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **循环次数变量**：循环体里面可以用系统变量「循环次数」表示当前是本指令的第几轮。它和上面参数里的「循环次数」、宏配置上的「循环次数」不是同一个东西。
2. **跳转**：循环体中执行 `流程跳转_循环-跳过本轮` 会进入下一轮，执行 `流程跳转_循环-跳出` 会结束最近一层循环。需要条件判断时，把跳转放入「如果／如果Pro」的分支中。
3. **和外层循环**：宏配置上的「循环次数」是整条宏再从头跑几遍；本指令是宏内部再套一层循环。
4. **暂停 / 终止**：循环过程中可被暂停或终止打断。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`循环序号`，带备注时为 `循环序号_备注`
- 示例：`循环1`、`循环1_点十次`

## 24 跳转

所属分类：流程

### 功能说明
在执行位置直接改变当前循环或分支的执行流程。编辑界面只有一个下拉框，选择跳转动作即可，无需配置编号。

### 类型说明
1. **循环-跳过本轮**：跳过本轮剩余指令，进入最近一层循环的下一轮。
2. **循环-跳出**：结束最近一层循环，继续执行该循环之后的指令。
3. **分支-跳出**：结束当前这一层分支指令，返回调用它的外层流程；顶层使用时结束本轮剩余指令。

### 使用方法
- 在「流程」类别选择「跳转」，从下拉框选择一种动作并确定。
- 需要有条件地跳转时，把它放入「如果／如果Pro」对应的分支指令中。
- 可以放在分支中间，执行到跳转处就生效，后面的相应循环体或分支指令不再执行。

### 特别说明
- 循环动作只针对最近一层循环。没有内层循环时，会作用于宏配置中的外层循环。
- 「分支-跳出」与「循环-跳出」范围不同：退出当前分支后，分支外的后续指令仍可执行。
- 旧配置里「如果／如果Pro」的流程控制字段继续兼容执行；新版编辑界面不再提供这些下拉框，新配置使用独立跳转指令。

### 指令格式
- `流程跳转_循环-跳过本轮`
- `流程跳转_循环-跳出`
- `流程跳转_分支-跳出`
- 不带序列号，不创建单独的指令配置文件。

## 25 如果

所属分类：流程

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/If.png)

1. **判断**：可添加任意数量；每一路可以单独开关。左值一般填变量名，右值可以是变量名或直接写的数字 / 文字。

4. **结果保存**：勾选后，把这次判断的真值或假值写入指定变量，方便后面再用。

2. **跳转指令的动作**：
   - **循环-跳过本轮**：立刻结束本轮循环体剩下的指令，进入下一轮。
   - **循环-跳出**：离开当前这一层「循环」指令。如果当前并不在循环指令里，则会结束整条宏的外层循环。
   - **分支-跳出**：跳过当前这一层还没执行的指令（例如搜索 / 如果分支里剩下的部分），然后回到上一层继续。在分支内使用时会回到外层继续；顶层使用时结束本轮剩余指令。
3. **和如果Pro**：本指令是一组条件、真假两条路。需要按优先级走多条不同分支时，用「如果Pro」。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`如果序号`，带备注时为 `如果序号_备注`
- 示例：`如果1`、`如果1_血量不足`

## 27 等待

### 指令格式

## 32 宏操作

所属分类：调控

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/MacroAction.png)

### 功能说明
1. **复用宏**：把另一条宏的指令接到当前流程里接着跑，或另外开一条同时跑。
2. **管控宏**：暂停、恢复或终止已经指定好的那条宏。

### 类型说明
1. **插入到当前宏**：把目标宏的指令展开进当前这条指令流，接着同步执行。目标宏如果是无限循环，也只插入一轮，避免把无限展开进来。
2. **触发**：另外启动目标宏，和当前宏同时跑（会再占一个执行线程）。
3. **暂停**：暂停正在运行的指定宏。目标当前没在跑，则本条没有效果。
4. **取消暂停**：恢复已经被暂停的指定宏。目标当前不是暂停状态，则本条没有效果。
5. **终止**：终止正在运行或已暂停的指定宏。目标两边都不是，则本条没有效果。

### 参数解析
1. **宏类型**：目标宏在哪个页签。可选按键宏 / 字串宏 / 菜单宏 / 界面宏 / 定时宏 / **宏**（子宏页签）/ **当前宏**（正在执行的这一条）。这里的「宏」指主界面那个没有热键的页签，不是泛指所有宏。
2. **宏序号**：目标宏在该页签列表里的序号。软件还会用序列码校正序号错位，避免中间删过条目后找错人。
3. **插入次数**：仅「插入到当前宏」时有效，表示把目标宏展开进来几遍。可填变量。
4. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **当前宏**：目标选「当前宏」时，操作的就是正在执行的这一条，不按序号去别的页签找。
2. **插入与触发**：插入不会多开一条并行宏，只是把指令接到当前流程后面；触发会再占一个 Worker / 线程，两边同时跑。
3. **子宏页签**：主界面「宏」页签里的条目自己没有热键，专门给人用本指令插入或触发。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`宏操作序号`，带备注时为 `宏操作序号_备注`
- 示例：`宏操作1`、`宏操作1_插入登录`

## 33 窗口管理

所属分类：调控

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/WindowManage.png)

### 功能说明
1. **找窗口**：按标题、类名、进程名找到目标窗口。
2. **改窗口**：对找到的窗口做激活、缩放、移动、置顶、改标题、改透明度、鼠标穿透等操作。
3. **读窗口**：用「获取窗口信息」把目标窗口的位置和大小读出来，存进变量。

### 类型说明
1. **激活窗口**：把后台或最小化的窗口带回前台并获得焦点。
2. **最大化 / 最小化 / 还原窗口**：调整窗口的显示状态。
3. **关闭窗口**：关掉这个窗口，但不会结束整个进程。进程可能仍留在托盘或后台。
4. **移动窗口**：把窗口左上角移到指定的屏幕坐标。
5. **调整大小**：设置窗口的宽度和高度。
6. **置顶 / 取消置顶**：窗口是否始终显示在其它窗口前面。
7. **修改标题**：改窗口标题栏上的文字。
8. **修改透明度**：0～100%，例如 `80%`。`0%` 完全透明，`100%` 完全不透明。
9. **开启 / 关闭鼠标穿透**：开启后，鼠标点击会穿过这个窗口，点到它后面的内容。
10. **获取窗口信息**：把窗口左上角坐标和窗口大小读出来，分别存进四个变量，供后面的指令使用。

### 参数解析
1. **窗口信息**：按 `标题⎖类名⎖进程名` 匹配。三项都空则本条不执行。支持 `{变量名}` 替换。可点「编辑」用鼠标选取。
2. **坐标 X / Y**：仅「移动窗口」使用，可填变量。
3. **宽度 / 高度**：仅「调整大小」使用，可填变量。
4. **新标题**：仅「修改标题」使用，可填变量。
5. **透明度**：仅「修改透明度」使用，范围 `0%`～`100%`，可填变量。
6. **坐标X存入 / 坐标Y存入 / 宽度存入 / 高度存入**：仅「获取窗口信息」使用，填接收结果的变量名。某一项留空就表示不取这一项。
7. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **关窗口不是杀进程**：关了窗口之后，程序可能仍在托盘或后台运行。
2. **只操作可见窗口**：按标题等模糊匹配时，会解析成当前可见窗口的句柄，避免误操作到隐藏窗口。
3. **找不到窗口**：查找值填错、窗口已经关掉，或没有可见的匹配项时，本条没有效果。
4. **获取窗口信息只读第一个窗口**：多个窗口同时匹配时，只读取最上面那个窗口的信息，和「激活窗口」的取法一致。
5. **坐标与大小的口径**：读的是整个窗口的外框（`WinGetPos`），包含标题栏和边框。界面绘图的客户区（去掉标题栏和边框）会略小一点。
6. **存到变量后要自己再用**：读取结果只是写进变量，不会改变窗口本身。拿到之后再用「移动窗口」「调整大小」等去用这些值。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`窗口管理序号`，带备注时为 `窗口管理序号_备注`
- 示例：`窗口管理1`、`窗口管理1_激活游戏`

## 34 RMT指令

所属分类：调控

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/rabit.png)

### 功能说明
1. **调软件能力**：调用软件自己的功能，例如截图、自由贴、指令显示、菜单轮盘、休眠。
2. **调系统输入**：启用或禁用鼠标、键盘，或开关鼠标加速。这类操作多数需要管理员权限。

### 类型说明
1. **图文**：截图（保存到 `Images\ScreenShot`）、截图并提取文本（识别结果放进剪贴板）、自由贴（把剪贴板里的图片或文本贴到桌面上）。
2. **输入控制**：启用 / 禁用鼠标、键盘或键鼠一起；启用 / 禁用鼠标加速。都需要管理员权限，否则不会生效。
3. **宏控制**：显示菜单（可指定轮盘序号）、关闭菜单、暂停所有宏、恢复所有宏、终止所有宏。
4. **调试**：开启 / 关闭变量监视，开启 / 关闭指令显示。
5. **软件自身**：休眠、重载、关闭软件。

### 参数解析
1. **类别 / 指令**：从上面五类里选一项具体指令。
2. **菜单序号**：仅「显示菜单」需要，对应菜单宏里那个模块的序号。

### 特别说明
1. **休眠**：立刻终止全部宏，并禁用软件功能，和主界面上的休眠是同一件事。
2. **终止所有宏**：停掉之后不能再恢复，只能重新触发。
3. **重载**：重新加载已经保存过的配置。还没点「应用并保存」的改动会丢掉。
4. **禁用键鼠**：务必先留好恢复办法（后面再跑一条启用、或准备好热键），否则本机键鼠会被挡住。

### 指令格式
- 格式：`RMT指令_类别_指令`，「显示菜单」为 `RMT指令_宏控制_显示菜单_序号`
- 示例：`RMT指令_调试_开启指令显示`、`RMT指令_宏控制_终止所有宏`

## 35 抓图

所属分类：其他

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/ScreenShot.png)

### 功能说明
1. **区域截图**：截取屏幕上的一块矩形，或某个窗口客户区里的一块矩形。
2. **给搜索用**：可以把保存后的图片完整路径写入变量，供后面的「搜索 / 搜索Pro」当作图片素材。

### 类型说明
1. **屏幕抓图**：按屏幕坐标截取，和哪个窗口在前无关。
2. **窗口抓图**：按窗口客户区坐标截取。窗口可以在后台。

### 参数解析
1. **抓图类型**：屏幕抓图 / 窗口抓图。
2. **窗口信息**：仅窗口抓图时使用，不能为空。可点「编辑」用鼠标选取。
3. **起始 / 终止坐标**：矩形的两个对角点，可填变量。起始坐标不能大于终止坐标。屏幕抓图填屏幕坐标，窗口抓图填该窗口客户区坐标。
4. **固定名称**：勾选后保存为 `名称.png`（名称不能为空）；不勾选则保存为 `序列号-时间戳.png`，每次文件名都不同。
5. **结果保存**：勾选后，把这次保存的图片完整路径写入变量。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 特别说明
1. **保存位置**：固定写到当前方案的 `Setting\<方案>\Images\TempShot`。安装目录没有写权限时，会改存到用户临时目录 `RMT_TempShot`。界面上不能自己指定保存路径。
2. **搜索引用**：搜索指令的图片路径填同一个变量名，就可以用刚抓下来的图去搜。
3. **覆盖**：勾选了固定名称时，重复抓图会覆盖同名文件。
4. **依赖 OpenCV**：本指令用 OpenCV 截图，插件不可用时会失败并提示。它和设置里的「截图方式」（微软 / RMT / SC）无关，那一项只给「RMT指令 · 截图」用。
5. **窗口抓图**：只截匹配到的第一个窗口，不会对多个窗口各截一张。

### 快捷键
1. **F1** / **左键框选截图范围**：框选后写入起始、终止坐标。

### 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`抓图序号`，带备注时为 `抓图序号_备注`
- 示例：`抓图1`、`抓图1_当前血条`

## 36 注释

所属分类：其他

**指令界面**

![配置界面](/RMT/Web/Images/MacroCMD/Comment.png)

### 功能说明
1. **加说明**：在指令流里插入一段给人看的文字，方便以后阅读。
2. **不执行**：运行到本条时直接跳过，不消耗时间，也不会改任何状态。

### 参数解析
1. **注释内容**：说明文字，不能为空。文字太长时，指令串里只显示前面 20 个字，完整内容仍保存在这条指令里。

### 特别说明
1. **不是跳过指令**：右键「跳过指令」会给某条可执行指令打上 `🚫`，那是暂时禁用它。注释本身就没有任何动作，不需要再跳过。
2. **和指令备注**：其它指令序列号后面的备注，只是那一条的名字；注释是单独占一条位置的指令，专门用来写说明。

### 指令格式
- 格式：`注释序号_内容摘要`
- 示例：`注释1_下面开始吃药`
