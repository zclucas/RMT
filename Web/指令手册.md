# 🚀 指令手册 - RMT（若梦兔）

本页按宏编辑器左侧的默认分类与顺序介绍 38 个指令：键鼠/手柄 → 搜索/识图 → 输入/输出 → 变量/数据 → 文件 → 流程 → 调控 → 其他。个人收藏区不影响本手册顺序。

各节名称与界面一致，介绍指令用途、类型、参数和执行注意事项。带序列号的指令将参数保存在配置中；备注只用于辨认。部分旧版内联指令格式仍可兼容，新增指令建议通过编辑器配置。

## 1 按键

<!-- 指令分类：键鼠/手柄 -->

![按键配置界面](/RMT/Web/Images/MacroCMD/Key.png)

### 📌 功能
1. **按下 / 松开 / 点击**：对界面里勾选的那些键，执行对应动作。
2. **组合键**：可以同时勾选多个键。执行时按勾选顺序一起按下；松开时按相反顺序抬起。

### 🧩 类型说明

| 动作 | 执行方式 |
| --- | --- |
| **按下** | 按下指定按键后立刻继续下一条（瞬发，本条不消耗时间）。 |
| **松开** | 松开指定按键后立刻继续下一条（瞬发）。 |
| **点击** | 先按下，等待「点击时间」后再松开；可以连续重复多次。 |

### ⚙️ 配置参数
1. **类型**：按下 / 松开 / 点击。只有选「点击」时，下面三项才生效。
2. **点击时间**：从按下到松开经过的时间（毫秒）。省略时默认 `100`。
3. **点击次数**：连续点击多少次。省略时默认 `1`。
4. **每次间隔**：两次点击之间的等待。新建编辑器预填 `200` 毫秒，已有指令省略这一段时执行为 `0`。点击多次时填写非负整数。

### 💡 特别说明

> 💡 **配对松开**
> 用「按下」之后，建议后面再配一条「松开」。只按不松就再按一次，后续按下可能无效（卡键）。

1. **瞬发**：按下、松开执行完立刻走下一条，本条本身不等待。
2. **连发**：需要明确重复发送按下与松开时，使用「点击」并设置点击次数。「按下」只发送按下事件。
3. **点击与长按**：点击时长控制按下与松开的间隔。目标程序自行决定怎样识别单击和长按。
4. **点击耗时**：本条实际占用的时间 ≈（点击时间 + 每次间隔）× 点击次数 − 每次间隔。最后一次松开后不会再等「每次间隔」。
5. **浮动**：点击时间受设置「点击时间浮动(%)」影响；每次间隔受「每次间隔浮动(%)」影响。按下、松开是瞬发，不受点击时间浮动影响。这两项也不是「间隔指令浮动」。
6. **结束松键**：这里说的是宏的**触发类型**（按下 / 松开 / 双击 / 长按 / 开关），不是本指令的按下 / 松开 / 点击。触发类型为按下、松开、双击、长按时，宏**正常跑完不会**自动松开仍按住的键。只有被终止，或触发类型是**开关**并结束时，才会兜底松开。因此「只按下不松开」在开关宏里看起来没事，换其它触发类型就容易卡键。
7. **宏设置 · 按键类型**：本指令不选择模拟方式，发送走的是该条宏「宏设置」里的按键类型。
   - **AHK Send**：通用，适合办公和多数游戏（管理员权限可让更多游戏有效）
   - **keybd_event**：系统接口，适合老软件或游戏（需管理员）
   - **罗技**：走罗技驱动（需管理员，G HUB 需为 2022.2.1154 及以前版本）
   - **AHI**：走 Interception 驱动（需管理员，并安装 Interception）
   - **VIIPER**：通过虚拟 USB 设备发送键鼠输入，需安装 usbip-win2 并启动 VIIPER 服务。
   记事本能触发、游戏里无效时，优先勾选「管理员启动」，再改这条宏的按键类型，而不是改本指令的点击时间。
8. **按下时按下**：宏已经把某键按住，又执行一次「按下」时，由设置「按下时按下」决定：自动松开（默认，先松再按）、忽略重复按下、允许重复按下（罗技模式可能卡死）。
9. **自触发**：keybd_event、罗技、AHI 模拟出的键可以作为宏的触发键。触发键不要和本指令输出的键相同，否则会自己触发自己形成死循环。
10. **点击时间建议**：建议不低于 **100ms**，低于 **30ms** 时后续指令容易丢失。不追求极限速度时，点击后再加一条间隔更稳。
11. **手柄**：键盘鼠标用本指令。虚拟手柄请用「手柄」指令。

### 键盘按键检测
1. 点击界面上的输入框。
2. 按下要模拟的目标按键或组合键。
3. 点击「确定」，软件会自动勾选对应按键，不必在列表里一个个找。

### 🧾 指令格式
- 按下：`按键_按键名_按下`
- 松开：`按键_按键名_松开`
- 点击：`按键_按键名_点击_点击时间_点击次数_每次间隔`
- 多键：键名之间用 `⎖` 连接，例如 `按键_Ctrl⎖a_点击_100`
- 示例：`按键_a_按下`、`按键_a_点击_100`、`按键_a_点击_100_10_200`。旧配置中的 `按键序号` 仍可执行，重新编辑保存后写为上述内联格式。

## 2 手柄

<!-- 指令分类：键鼠/手柄 -->

![手柄配置界面](/RMT/Web/Images/MacroCMD/Joy.png)

### 📌 功能
1. **按钮 / 方向键**：在手柄图上点击按键，执行按下、松开或点击。可组合多个按键。
2. **摇杆 / 扳机轴**：点击摇杆盘或扳机轴条，设置轴值并保持，直到下一条同轴指令覆盖（轴值 0 即回中）。

### 🧩 类型说明

| 输入类型 | 取值与动作 |
| --- | --- |
| **按下 / 松开 / 点击** | 与「按键」指令相同，仅作用于手柄按钮和方向键。 |
| **轴值** | 摇杆 LX/LY、RX/RY 各轴范围 `-100 ~ 100`（0 为中心）。真实手柄两轴独立饱和，合成向量按圆形限位（半径约 125），因此可以出现 `LX:100_LY:67`，不会出现 `LX:100_LY:100`。扳机 LT/RT 范围 `0 ~ 100`。 |

### 💡 特别说明
1. 使用前需要安装软件 Joy 目录下的 **ViGEmBus.exe**，否则手柄键发不出去。
2. 设置里的**宏手柄类型**（Xbox / DS4）决定游戏实际收到哪种虚拟手柄；**手柄映射**只改界面上按键名称怎么显示（例如 A 还是 ×），不改实际输出。
3. 手柄输出走 ViGEm 虚拟手柄，不走 AHK / 罗技 / AHI 键盘通道。
4. 旧宏里写在「按键」指令中的手柄键仍可执行；重新编辑后会保存为「手柄」指令。
5. 打开编辑器后，按真实手柄按键或推动摇杆会自动选中并写入对应值。
6. 一条指令可同时设轴值并操作按钮。执行时先设置各轴，再按所选方式处理按钮。按钮的点击时长和间隔以毫秒为单位。
7. 要保存 `LT:50` 这样的中间值，请在设置中关闭「LT、RT按键化」或「L2、R2按键化」。按钮模式下重新保存会把正轴值转成扳机按钮，按下时输出满量程。

### 🧾 指令格式
- 按钮：`手柄_A_点击_点击时间_点击次数_每次间隔`
- 组合：`手柄_A+B_按下`
- 方向：`手柄_上_按下`
- 摇杆：`手柄_LX:80`、`手柄_LX:80_LY:20`
- 扳机：`手柄_LT:50`
- 示例：`手柄_A_点击_100`、`手柄_LB_按下`、`手柄_RT:100`

## 3 移动

<!-- 指令分类：键鼠/手柄 -->

![移动配置界面](/RMT/Web/Images/MacroCMD/Move.png)

### 📌 功能
按固定坐标移动鼠标指针。可选择绝对移动或相对移动；需要变量坐标、移动后点击、窗口坐标或拟真轨迹时，使用「移动Pro」。游戏视角位移使用「增量移动」。

### 🧩 类型说明
1. **绝对移动**：填写目标点的屏幕坐标。
2. **相对移动**：填写相对于当前指针的偏移量。例如当前位于 `(100,100)`，填写 `10,0`，目标为 `(110,100)`。

### ⚙️ 配置参数

| 参数 | 取值 |
| --- | --- |
| **坐标 X / Y** | 填写有符号整数。绝对移动支持主屏左侧或上方显示器的负坐标，相对移动时负数向左或向上。 |
| **移动速度** | 执行时限制在 0～100，越大越快，100 为最快，默认 90。 |
| **移动方式** | 绝对移动或相对移动。 |

### 💡 特别说明
- 移动方式跟随宏设置中的按键类型，支持普通、罗技或 AHI 等发送方式。
- 本指令只移动，不点击；坐标受设置中的坐标浮动影响。
- 兼容名称「鼠标移动」，当前界面名称为「移动」。

### ⌨️ 快捷键
- **F1**：绝对模式填入当前鼠标屏幕坐标；相对模式用当前屏幕坐标减去框内原值，手动填写可直接指定偏移。
- **标题栏预览按钮**：切换指令预览，在屏幕上持续显示主题配色的路径箭头；再次点击或关闭编辑器后关闭。相对移动按当前指针加偏移显示。预览不会执行鼠标动作。

### 🧾 指令格式
- 当前编辑器将参数保存到配置中，宏中写 `移动序号` 或 `移动序号_备注`。
- 示例：`移动1`、`移动1_800 600`。
- 兼容旧内联格式：`移动_坐标X_坐标Y_移动速度_移动方式`，移动方式 `0` 表示绝对、`1` 表示相对。

## 4 移动Pro

<!-- 指令分类：键鼠/手柄 -->

![移动Pro配置界面](/RMT/Web/Images/MacroCMD/MovePro.png)

### 📌 功能
按坐标移动鼠标，并可在到达后单击、双击或按住左键拖拽。支持变量坐标、窗口坐标基准和拟真轨迹。

### 🧩 类型说明

| 坐标基准 | 定位方式 |
| --- | --- |
| **屏幕基准** | 绝对移动时按屏幕坐标定位；相对移动时以当前指针位置为起点。 |
| **窗口基准** | 按所选窗口左上角加偏移计算目标点，使用绝对移动。 |

### ⚙️ 配置参数
1. **坐标基准**：屏幕或窗口。窗口基准需要填写窗口信息，可通过编辑按钮选择目标窗口。
2. **坐标 X / Y**：可填数值或变量；含义由坐标基准、移动方式和鼠标动作决定。绝对拖拽时显示为「起始点」。
3. **终止点**：仅在绝对移动的「A到B拖拽」中显示，支持数值和变量。普通「拖拽」只需填写目标点或偏移量。
4. **移动方式**：绝对移动或相对移动；窗口基准下固定使用绝对移动。
5. **鼠标动作**：移动、移动后单击、移动后双击、拖拽，绝对移动时还可选 A到B拖拽。
   - **拖拽**：从当前指针位置按住左键，拖到目标点或按 X / Y 偏移拖动，再松开。
   - **A到B拖拽**：先移到起始点，再按住左键拖到终止点。
6. **移动速度**：0～100，越大越快，100 为瞬间到达。
7. **拟真轨迹**：启用后按更接近人手的轨迹移动。
8. **备注**：帮助辨认指令，不改变执行行为。

### 💡 特别说明
- 本指令移动真实鼠标指针。窗口基准用于定位，后台点击请使用「后台鼠标」。
- 移动、点击以及拖拽的按下与松开，都跟随宏设置中的按键类型，支持普通、罗技或 AHI 等发送方式。
- 拟真轨迹启用后鼠标动作锁定为「移动」，且「移动方式」「鼠标动作」不可再调整；取消勾选后恢复可选。罗技或 AHI 按键类型下按普通轨迹移动，不使用拟真轨迹。
- 坐标受设置中的坐标浮动影响；窗口基准下找不到目标窗口、或坐标为尚未取到值的变量时，本条指令不执行。
- 拖拽结束后会自动松开左键；中途报错或中断时同样会松开，避免左键保持按下。
- 罗技、AHI、VIIPER 模式下，相对移动完成后会短暂延时再点击。
- 旧版「移动Pro」的游戏视角功能已单独放入「增量移动」，当前界面不再通过屏幕规格配置多套坐标；旧配置仍按原来的相对位移方式兼容执行。

### ⌨️ 快捷键
- **F1**：取当前鼠标坐标。相对移动下按已填坐标折算成偏移量；拖拽时先聚焦起始或终止坐标框，再取对应点位。
- **标题栏预览按钮**：切换指令预览，在屏幕上持续显示主题配色的路径箭头；再次点击或关闭编辑器后关闭。以按钮点亮时的指针位置作为起点，拖拽显示起点到终止点，窗口基准按目标窗口左上角对齐。坐标是变量时无法预览，会提示先换成数值；窗口基准下未找到目标窗口也会提示。预览只画线，不会真的移动鼠标。

### 🧾 指令格式
- 参数保存在配置中，宏中写序列号。
- 格式：`移动Pro序号` 或 `移动Pro序号_备注`
- 示例：`移动Pro1`、`移动Pro1_点按钮`
- 旧名称 `鼠标移动Pro序号` 仍可识别执行，建议改用新名称。

## 5 增量移动

<!-- 指令分类：键鼠/手柄 -->

![增量移动配置界面](/RMT/Web/Images/MacroCMD/DeltaMove.png)

### 📌 功能
发送相对鼠标位移，适合第一／第三人称游戏转动视角，也可重复发送同一偏移。该功能从旧版「移动Pro」的游戏视角模式中独立出来。

### ⚙️ 配置参数

| 参数 | 位移规则 |
| --- | --- |
| **X / Y 偏移** | 整条指令的水平与垂直总位移，可填写数值或变量。负值向左或向上。 |
| **偏移次数** | 总位移拆成的步数，默认为 `1`。例如偏移 `10`、次数 `3`，三个步长合计仍为 `10`。 |
| **每次间隔** | 相邻两步之间等待的毫秒数，最后一步后不再等待。 |
| **备注** | 便于辨认这条指令。 |

### 💡 特别说明
- 使用相对位移接口，不把 X / Y 当作屏幕上的目标点；不附带鼠标点击或拟真轨迹。
- 游戏中的实际转动角度受游戏灵敏度和输入处理影响。先用较小位移与次数试运行。
- 此类游戏视角位移固定走 `mouse_event`，不随宏的罗技或 AHI 按键类型切换。

### ⌨️ 快捷键
- **标题栏预览按钮**：切换指令预览，以圆点标出每一步的落点并显示整体路径箭头；修改参数后自动刷新，再次点击或关闭编辑器后关闭。位移与次数需填数值，预览不会执行鼠标动作。

### 🧾 指令格式
- 参数保存在配置中，宏中写 `增量移动序号` 或 `增量移动序号_备注`。
- 示例：`增量移动1`、`增量移动1_向右转`

## 6 后台按键

<!-- 指令分类：键鼠/手柄 -->

![后台按键配置界面](/RMT/Web/Images/MacroCMD/BGKey.png)

### 📌 功能
1. **后台按键**：向指定窗口发送按键消息，不会占用真实键盘，其它窗口也收不到这些键。
2. **可组合**：可以同时勾选多个键，按组合键发送。

### 🧩 类型说明

| 动作 | 发送方式 |
| --- | --- |
| **按下** | 向目标窗口发送按下，然后立刻继续下一条（瞬发）。 |
| **松开** | 向目标窗口发送松开，然后立刻继续下一条（瞬发）。 |
| **点击** | 先按下，等待「点击时间」后再松开；可以连续重复多次。 |

### ⚙️ 配置参数
1. **窗口绑定**：可继承宏的绑定，或通过「编辑」选取目标。使用标题、类名或进程名匹配多个窗口时，会向各匹配窗口发送消息。
2. **类型**：按下 / 松开 / 点击。
3. **点击时间**：从按下到松开经过的时间，默认 `100` ms，受设置「点击时间浮动(%)」影响。
4. **点击次数**：连续点击多少次，默认 `1`。
5. **每次间隔**：两次点击之间的等待，默认 `100` ms，受设置「每次间隔浮动(%)」影响。仅选点击且次数大于 1 时生效。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 💡 特别说明

> 💡 **部分窗口无效**
> 很多游戏、部分程序不接收后台按键。有的窗口还必须管理员启动软件才有效。浏览器看起来按下了但页面没反应时，通常是该窗口不支持后台。

1. **不是连发**：选「按下 `a`」不会像长按键盘那样自动反复输入 `a`。
2. **配对松开**：用「按下」之后建议再配一条「松开」，否则目标窗口里可能卡键。组合键松开时按相反顺序抬起。
3. **点击耗时**：最后一次松开后直接继续。窗口收到长按还是单击，取决于它如何处理收到的消息。
4. **和前台按键**：本指令走窗口消息，不走宏设置里的 AHK / 罗技 / AHI，也不占用真实键盘。

### ⌨️ 快捷键
1. **F1**：按当前配置立刻模拟执行一次，和界面上的「模拟指令」相同。其它指令里的 F1 多半是取坐标，不要和这里搞混。
2. **选键**：可点击键盘图上的按键，或在编辑器内按下实际按键。编辑数字字段时可直接输入参数。

## 10 搜索

<!-- 指令分类：搜索/识图 -->

![搜索配置界面](/RMT/Web/Images/MacroCMD/Search.png)

### 📌 功能
1. **屏幕搜索**：在屏幕指定范围内查找图片、颜色或文本。
2. **分支执行**：找到或没找到时，可以分别执行一段指令（不填则只搜、不分支）。
3. **简化配置**：本指令是「搜索Pro」的简化版。默认只搜 1 次、相似度约 90。窗口搜索、改相似度、多次重试、把结果或坐标写入变量等，见「搜索Pro」。

### 🧩 类型说明

| 搜索目标 | 输入方式 |
| --- | --- |
| **屏幕图片** | 在范围内匹配目标图片。图片可以选本地文件，或用 F2 当场截图。 |
| **屏幕颜色** | 在范围内查找指定颜色。颜色可以手填 HEX，或用 F3 取当前鼠标位置的颜色。 |
| **屏幕文本** | 在范围内匹配文字，支持正则表达式。 |

### ⚙️ 配置参数
1. **搜索范围**：在编辑器中填写四个整数屏幕坐标。起始点需在终止点左上方或与其重合。找图时范围至少要容纳素材，OCR 则需要有宽和高的区域。需要变量坐标时，使用「搜索Pro」。

5. **备注**：写在指令串序列号后面，只用于辨认，不影响搜索。

### 💡 特别说明

> 💡 **分支前加间隔**
> 找到后会先做鼠标动作，再执行「找到后」分支。目标程序反应慢时，分支开头需要加间隔，避免点完立刻做下一步。

1. **匹配方式**：找图和找色比较像素特征，找文字先做 OCR 再匹配文本。目标尺寸、缩放或背景变化时可能需要重新选图。
2. **文本支持正则**：搜索文本可按正则匹配。
3. **范围与素材**：范围越小、图片越小，速度越快。截图只截特征部分，不要带会变化的背景（推荐 32×32 或 48×48）。
4. **dll 加载失败**：图片或文本搜索提示 dll 失败时，请看「问题及应对措施」，或到工具页做文件校验补齐插件。
5. **图片丢失**：提示图片不存在时，若软件目录变过，到配置管理做「配置校准」。
6. **和搜索Pro**：两者用同一套执行引擎。本指令默认搜 1 次、相似度约 90，不能做窗口搜索、不能无限重试、不能把成败或坐标写入变量；需要这些时用搜索Pro。

### ⌨️ 快捷键
1. **F1**：开启框选范围（左键松开后关闭）。
2. **F2**：截图作为搜索图片素材，并根据图片位置、大小自动选取搜索范围。
3. **F3**：选取当前鼠标位置颜色值作为颜色搜索的素材。
4. **定位取色器**：更精细地确定坐标、拾取颜色。
5. **范围预览**：点击坐标标签切换预览，拖动预览边框可回填范围。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`搜索序号`，带备注时为 `搜索序号_备注`
- 示例：`搜索1`、`搜索1_找血条`

## 11 搜索Pro

<!-- 指令分类：搜索/识图 -->

![搜索Pro配置界面](/RMT/Web/Images/MacroCMD/SearchPro.png)

### 📌 功能
1. **屏幕搜索**：在屏幕指定范围内查找图片、颜色或文本，并按找到 / 未找到执行分支。
2. **窗口搜索**：在匹配窗口的客户区内搜索。窗口可以在后台，最小化后能否搜索取决于窗口能否被捕获。
3. **结果保存**：可以把成功 / 失败写入变量；找到时也可以把目标中心点坐标写入变量。
4. **完整配置**：和「搜索」用同一套执行引擎。搜索是简化版；本指令可以改相似度、次数、间隔、识图模型和窗口信息，并支持图片自适应匹配。

### 🧩 类型说明

| 搜索范围 | 坐标基准 |
| --- | --- |
| **屏幕图片 / 屏幕颜色 / 屏幕文本** | 在屏幕坐标范围内搜索。 |
| **窗口图片 / 窗口颜色 / 窗口文本** | 使用客户区坐标，需要为目标窗口设置范围。 |

### ⚙️ 配置参数
1. **图片识别自适应**：在「设置 → 系统 → 通用」的「图片识别模型」下方统一开启，对所有使用 OpenCV 的图片搜索生效，尝试匹配因分辨率或 DPI 缩放变化而改变大小的目标。默认关闭；颜色、文本搜索及 RMT 识图不使用此选项。换设备后仍需检查搜索范围是否覆盖目标，必要时重新截图和框选。
2. **搜索范围**：从起始坐标到终止坐标围成的矩形。起始不能大于终止；做图片搜索时，范围不能小于图片。坐标可填整数或变量。
3. **搜索目标**：图片选本地文件或截图（路径也可引用变量）；颜色填 HEX 或用 F3 取色；文本可输入内容（支持正则）或引用变量。
4. **相似度**：值越大匹配越严格，越不容易误搜到别的东西。只对图片、颜色生效，文本搜索不用这项。
5. **搜索次数**：没找到就再试，直到找到或次数用尽。也可以选「无限」，一直等到出现。
6. **每次间隔**：两次搜索之间的等待。只在次数大于 1 或选了无限时生效。受设置「每次间隔浮动(%)」影响，不是「间隔指令浮动」。
7. **鼠标动作**：
   - 屏幕：无动作 / 移动到目标 / 移动到目标并点击（可设移动速度、点击次数；速度 100 为瞬间到达）
   - 窗口：无动作 / 后台鼠标到目标点击 / 后台鼠标到目标双击（不移动真实光标）
8. **窗口信息**：窗口搜索时必填。可以填窗口句柄，或按 `标题⎖类名⎖进程名` 三项来匹配（某一项可以留空）。同时匹配到多个窗口时，鼠标动作会对每个匹配窗口各做一次。
9. **图片识别模型**：OpenCV（推荐，支持 32/64 位）：默认按灰度匹配，相似度不再自动切换颜色模式。搜索 Pro 和搜索 Combo 的图片目标可在相似度右侧勾选「颜色匹配」，默认不勾选；勾选后会比较图像颜色，自适应缩放时也会校对颜色。RMT 识图走 AHK `ImageSearch`，不显示该选项。
10. **OCR类型**：在设置 → 系统 → 通用中选择 RapidOCR（默认）或 Tesseract OCR，保存后应用于后台宏。两者均识别中文、英文和数字；截图取字、搜索与变量提取共用此设置。
11. **分支指令**：「找到后」和「未找到后」两段指令都可以留空。
12. **结果保存**：勾选后，找到写入真值、没找到写入假值。
13. **目标点保存**：找到后写入坐标，未找到时保留原值。屏幕模式写屏幕坐标，窗口模式写客户区坐标。匹配多个窗口时，单组变量保留最后一次写入的位置。
14. **备注**：写在指令串序列号后面，只用于辨认，不影响搜索。

### 💡 特别说明

> 💡 **无限次数**
> 会一直搜到找到为止，之后只走「找到」分支，「未找到」分支不会触发。暂停、终止可以打断。

1. **搜索不是识别**：源素材要和目标基本一致才能搜到。它比的是像素是否像，不是「看懂画面」。
2. **耗时**：本条实际占用的时间 ≈（单次检索时间 + 每次间隔）× 实际搜索次数 − 每次间隔。最后一次搜完后不会再等「每次间隔」。
3. **分支前加间隔**：找到后先做鼠标动作，再执行「找到后」分支。目标程序反应慢时，分支开头需要加间隔。
4. **范围与素材**：范围越小、图片越小，速度越快。图片推荐只截特征，大约 32×32，不要带会变的背景。文本推荐多字一起搜，单字符容易不准。
5. **截图后改大小**：用 SC 截图后如果又改了图片大小，搜索范围需要重新框选，否则范围和素材对不上。
6. **dll 加载失败**：请看「问题及应对措施」，或到工具页做文件校验。
7. **图片丢失**：软件目录变过时，到配置管理做「配置校准」。
8. **编辑器测试计时**：成功命中时显示实际检索耗时。重试间隔、鼠标动作及分支执行时间另计。

### ⌨️ 快捷键
1. **F1**：开启框选范围（左键松开后关闭）。
2. **F2**：截图作为搜索图片素材，并根据图片位置、大小自动选取搜索范围。
3. **F3**：选取当前鼠标位置颜色值作为颜色搜索的素材。
4. **定位取色器**：更精细地确定坐标、拾取颜色。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`搜索Pro序号`，带备注时为 `搜索Pro序号_备注`
- 示例：`搜索Pro1`、`搜索Pro1_找血条`

## 13 搜索Combo

<!-- 指令分类：搜索/识图 -->

![搜索Combo配置界面](/RMT/Web/Images/MacroCMD/SearchCombo.png)

### 📌 功能
在同一条指令中配置多个搜索目标，按「满足个数」判断本轮搜索是否成功。各目标可分别使用图片、颜色或文本搜索，也可分别选择屏幕或窗口搜索。

### ⚙️ 配置参数

| 配置项 | 组合规则 |
| --- | --- |
| **目标列表** | 添加、删除并选择当前编辑的目标。每个目标独立设置搜索类型、窗口信息、范围、目标内容、相似度和识别模型。 |

- 只查一个目标时优先使用「搜索」或「搜索Pro」。旧版多目标搜索Pro可在本编辑器中继续编辑。

### ⌨️ 快捷键
- **F1**：框选当前目标的搜索范围。
- **F2**：为当前目标截图。
- **F3**：取色。

### 🧾 指令格式
- 参数保存在配置中，宏中写 `搜索Combo序号` 或 `搜索Combo序号_备注`。

## 17 变量提取

<!-- 指令分类：变量/数据 -->

![变量提取配置界面](/RMT/Web/Images/MacroCMD/Extract.png)

### 📌 功能
1. **抽取文本**：先从屏幕、剪贴板或窗口得到一段文字，再按模板从中取出数字或文字，写入变量。
2. **可重试**：识别失败或模板对不上时，可以按次数、间隔再试。

### 🧩 类型说明

| 来源 | 提取方式 |
| --- | --- |
| **屏幕** | 对屏幕上的一块矩形做 OCR，再按模板提取。 |
| **剪切板** | 不对屏幕识字，直接对剪贴板里已有的文本提取。 |
| **窗口** | 对指定窗口客户区做 OCR 后再提取。窗口可以在后台，不必露在最前面。 |

### ⚙️ 配置参数
1. **提取源**：屏幕 / 剪切板 / 窗口。
2. **提取文本**：模板留空时，只勾选第 1 路，用它接收完整文本。`&x` 提取数字，`&c` 提取文本。模板中的 `{变量名}` 会先替换再匹配。
3. **搜索次数 / 每次间隔**：没提取成功就再试，直到成功或次数用尽。间隔受「每次间隔浮动」影响。
4. **窗口信息**：仅窗口提取时使用。可以填句柄，或按 `标题⎖类名⎖进程名` 匹配。同时匹配到多个窗口时，会对每个窗口各处理一次。
5. **OCR类型**：跟随设置中的 RapidOCR / Tesseract OCR。RapidOCR 使用 PP-OCRv6 模型；Tesseract 使用 `Plugins\TesseractOcr\tessdata` 下的 `chi_sim.traineddata` 和 `eng.traineddata`。两种模型不兼容，不能通过修改 RapidOCR 字符表为 Tesseract 增字。
6. **提取范围**：屏幕提取使用屏幕坐标，窗口提取使用客户区坐标。可用 F1 框选。
7. **结果保存**：最多 6 路，按模板中占位符的位置对应。例如只勾选第 2 路时，模板仍需有至少两个占位符。勾选「变量存在忽略」后，已有结果保留原值。
8. **备注**：写在指令串序列号后面，只用于辨认。

### 💡 特别说明

> 💡 **可能失败**
> OCR 看错字，或识别结果对不上模板时，这次提取会失败，不会写入提取值。

1. **失败时怎么写变量**：
   - 变量还不存在，且这次失败：创建该变量，值为 `0`
   - 变量已经存在，且这次失败：不改原来的值
   - 提取成功：写入这次提取到的值
2. **模板示例**：
   - `&x`：取出第一个数字
   - `&c`：取出第一段文本
   - `HP：&x`：从 `HP：3,000` 取出 `3000`
   - `坐标(&x,&x)`：从 `坐标(10.5,8.6)` 取出两个数
   - `{Title}：&x`：若变量 `Title` 当前是 `血量`，则去匹配 `血量：20.5` 并取值
3. **无限次数**：会一直抽到成功为止；暂停、终止可以打断。

### ⌨️ 快捷键
1. **F1**：左键框选提取范围。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`变量提取序号`，带备注时为 `变量提取序号_备注`
- 示例：`变量提取1`、`变量提取1_读血量`

<!-- 指令分类：变量/数据 -->

2. **输出展开**：输出指令里用 `{ε数组名}` 可以把数组内容展开成文本。
3. **全局**：数组和变量一样是全局的，所有宏共用同一个名字。

### 🧩 类型说明

| 处理类型 | 行为 |
| --- | --- |
| **文本分割** | 按分隔文本切开、按固定长度切开，或按正则切开。 |

| **大小写转换** | 全部大写、全部小写，或将各词转为首字母大写。 |

### ⚙️ 配置参数

2. **类型选项 / 类型参数**：随上面的处理类型变化，例如分隔符、每段长度、查找文本、替换文本、正则。
3. **保存名称**：「文本分割」「文本提取」写入数组，其余类型写入变量。
4. **备注**：写在指令串序列号后面，只用于辨认。

### 💡 特别说明

> 💡 **替换与提取**
> 正则替换可在替换文本中用 `$1` 引用捕获组。正则提取收集完整匹配，找不到时写入空数组。

1. **分割结果**：切开后一般是多段，通常保存到数组，再用「数组」指令按位置取值。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`文本处理序号`，带备注时为 `文本处理序号_备注`

## 23 网络请求

<!-- 指令分类：文件 -->

![网络请求配置界面](/RMT/Web/Images/MacroCMD/HttpRequest.png)

向 HTTP/HTTPS 服务发送请求，适合 webhook、本地服务和配置读取。支持 GET、POST、PUT、DELETE；GET 不发送 Body。


### ⚙️ 配置参数

| 请求配置 | 行为 |
| --- | --- |
| **URL / Header / Body** | URL、请求头的值和 Body 支持 `{变量名}`，执行时替换。Header 每行填写 `名称: 值`。 |
| **Body 类型** | JSON、表单、原始文本。JSON 与原始文本按替换后的内容发送；表单每行填写 `名称=值`，名称和值分别自动进行 UTF-8 URL 编码，可重复同名字段。 |
| **Content-Type** | 按 Body 类型自动设置；Header 中显式填写时以填写值为准。 |
| **超时** | 每次尝试的总时限，单位毫秒，默认 10000，范围 1～3600000。 |
| **失败重试次数** | 默认 0，可填 0～10 或引用 `{变量名}`。网络失败、超时及 HTTP 408、429、5xx 会在 500 毫秒后重试，最多请求 `1 + 重试次数` 次。POST 重试可能重复提交。 |
| **结果变量** | 分别保存状态码、响应体、错误信息，默认 `HTTP状态码`、`HTTP响应体`、`HTTP错误信息`。无 HTTP 响应时状态码为 0；HTTP 错误仍保留状态码和响应体；每次执行会覆盖结果，防止使用旧响应。 |
| **重定向** | 返回原始 3xx，不自动跟随，避免认证头转发到其他主机。HTTPS 使用系统证书校验。 |

### 🧪 请求示例

例如设置 POST，URL 为自己的 webhook，Header 填写：

```text
Authorization: Bearer {服务密钥}
```

JSON Body：

```json
{"text":"{识别结果}"}
```

后续使用「如果」检查 `HTTP状态码` 是否为 200，再使用「变量提取」处理 `HTTP响应体`。JSON 内变量替换不自动转义；变量含引号或换行时，需先构造合法 JSON，也可让 Body 整体引用 `{请求JSON}`，或改用自动编码的表单。

密钥建议在运行时通过输入等方式放入变量。变量引用不会把实际值写回本指令，但如果密钥仍写在其它指令或变量初始值中，导出配置时仍可能包含它。宏中止时会取消正在等待的请求；服务端已收到的操作无法撤回。

### 🧾 指令格式

- 参数保存在配置中，宏中写 `网络请求序号` 或 `网络请求序号_备注`。
- 示例：`网络请求1_读取本地服务`。

## 24 间隔

<!-- 指令分类：流程 -->

![间隔配置界面](/RMT/Web/Images/MacroCMD/Delay.png)

### 📌 功能
1. **插入间隔**：插在两条指令中间。执行到本条时先等待，再继续后面的指令。
2. **循环间隔**：把本条放在整段宏的最后。外层每一轮指令都跑完后，会先等这段时间，再开始下一轮。它不会改变宏配置里的「循环次数」。

### 🧩 类型说明

| 模式 | 取值规则 |
| --- | --- |
| **固定** | 每次都等待同一个时长。 |
| **随机** | 在时间 A 和时间 B 之间抽一个时长。每次执行重新抽取，再应用「间隔指令浮动」。 |

### ⚙️ 配置参数
1. **整数**：等待时长，单位是毫秒。例如 `3000` 表示 3 秒，`0` 等于不等待。
2. **变量**：读取变量的当前值，当作等待时长（同样是毫秒）。

### 💡 特别说明

> 💡 **间隔指令浮动**
> 设置页「间隔指令浮动(%)」只作用于本指令。未写正负号时上下都浮动，例如间隔 `3000`、浮动 `10`，实际约 `2700～3300` ms。按键连点、搜索多次之间的等待走的是「每次间隔浮动」，与本项无关。

1. **循环间隔**：宏要循环几遍，由这条宏配置上的「循环次数」决定，本指令改不了这个数字。放在末尾只是让每一轮跑完后再等待，再进入下一轮；随机间隔每轮会重新抽取。
2. **中断**：等待期间可暂停或终止宏。要等待某个条件或给出超时结果时，使用「等待」指令。

### 🧾 指令格式
- 固定：`间隔_时间A_备注`
- 随机：`间隔_时间A~时间B_备注`
- 示例：`间隔_500`、`间隔_500_等待`、`间隔_500~1000`、`间隔_500~1000_随机等待`
- 旧配置中的 `间隔序号` 仍可运行，编辑保存后使用上述格式。

- 参数保存在配置中，宏中写 `等待序号` 或 `等待序号_备注`。

## 26 循环

<!-- 指令分类：流程 -->

![循环配置界面](/RMT/Web/Images/MacroCMD/Loop.png)

### 📌 功能
1. **重复执行**：按指定次数，反复执行循环体里的那一段指令。
2. **条件控制**：可以在每一轮开始时先判断条件，再决定本轮要不要跑、或要不要离开循环。

### 🧩 类型说明

| 条件类型 | 本轮是否执行 |
| --- | --- |
| **无** | 不设条件，只按「循环次数」执行。次数到了就结束。 |
| **继续条件** | 每一轮先判断。条件成立才执行循环体；不成立则离开循环。 |
| **退出条件** | 每一轮先判断。条件成立则立刻离开循环，不再执行本轮循环体。 |

### ⚙️ 配置参数
1. **循环次数**：设置循环体最多执行多少轮，可填次数、选择变量或选择「无限」。条件仍可提前结束循环。
2. **循环条件**：无 / 继续条件 / 退出条件。可添加任意数量，比较方式和「如果」相同。
3. **逻辑关系**：多路条件之间用「且」（全部成立才算成立）或「或」（有一路成立就算成立）。
4. **循环体**：每一轮要跑的指令组合。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 💡 特别说明

> 💡 **循环次数变量**
> 循环体可读取系统变量「循环次数」，第一轮为 `1`。每轮开始时先更新该变量，再判断条件。

1. **跳转**：在循环体中添加「宏操作」，宏类型选「当前宏」。「循环-跳出本轮」进入下一轮，「循环-跳出」结束最近一层循环。需要条件判断时，把宏操作放入「如果／如果Pro」的分支中。
2. **和外层循环**：宏配置上的「循环次数」是整条宏再从头跑几遍；本指令是宏内部再套一层循环。
3. **暂停 / 终止**：循环过程中可被暂停或终止打断。
4. **取值失败**：判断条件需要的变量取不到时，循环结束。要检查变量是否存在，可选择「变量存在」。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`循环序号`，带备注时为 `循环序号_备注`
- 示例：`循环1`、`循环1_点十次`

### 📌 功能
1. **条件分支**：按判断结果执行「成立」或「不成立」那一段指令。两段都可以留空，只判断、不分支。
2. **条件跳转**：在对应分支中添加「宏操作」，宏类型选「当前宏」，再选择跳转动作。

### 🧩 类型说明

| 比较方式 | 判断内容 |
| --- | --- |
| **大于 / 大于等于 / 等于 / 不等于 / 小于等于 / 小于** | 比较左右两边的数值。 |
| **字符包含** | 左边这段文字里，是否包含右边这段文字。 |
| **变量存在** | 左边这个变量名当前是否已经存在。 |
| **正则匹配** | 检查左值是否匹配右侧的正则表达式，例如 `^OK` 匹配以 `OK` 开头的文本。 |

### ⚙️ 配置参数
1. **判断**：可添加任意数量；每一路可以单独开关。左值一般填变量名，右值可以是变量名或直接写的数字 / 文字。
2. **逻辑关系**：「且」表示已启用的条件全部成立才算成立；「或」表示有一路成立就算成立。
3. **分支指令**：「成立后」和「不成立后」两段都可以留空。
4. **结果保存**：勾选后，按判断结果把配置的「真值」或「假值」写入指定变量。两个值可自定义，例如 `通过` 和 `拒绝`。
5. **备注**：写在指令串序列号后面，只用于辨认。

### 💡 特别说明

> 💡 **变量取值**
> 一般比较找不到所需变量时，会停止本条判断，既不保存结果也不执行分支。用「变量存在」可把缺少变量当作一个可分支的结果。

1. **执行顺序**：先写入结果变量，再执行对应分支里的指令。分支可以使用刚保存的结果，跳转在执行到所在位置时生效。
2. **跳转指令的动作**：
   - **循环-跳出本轮**：立刻结束本轮循环体剩下的指令，进入下一轮。
   - **循环-跳出**：离开当前这一层「循环」指令。如果当前并不在循环指令里，则会结束整条宏的外层循环。
   - **分支跳出**：跳过当前分支剩余指令，回到上一层继续。顶层使用时结束本轮剩余指令。
3. **和如果Pro**：本指令是一组条件、真假两条路。需要按优先级走多条不同分支时，用「如果Pro」。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`如果序号`，带备注时为 `如果序号_备注`
- 示例：`如果1`、`如果1_血量不足`

3. **起始 / 终止坐标**：可填变量。横向和纵向的终止坐标都要大于起始坐标，差值就是图片的宽和高。屏幕抓图用屏幕坐标，窗口抓图用客户区坐标。
4. **固定名称**：勾选后保存为 `名称.png`（名称不能为空）。取消勾选后，软件用序列号、时间和唯一后缀为每次抓图生成名称。
5. **结果保存**：勾选后，把这次保存的图片完整路径写入变量。
6. **备注**：写在指令串序列号后面，只用于辨认。

### 💡 特别说明

> 💡 **保存位置**
> 固定写到当前方案的 `Setting\<方案>\Images\TempShot`。安装目录没有写权限时，会改存到用户临时目录 `RMT_TempShot`。界面上不能自己指定保存路径。

1. **搜索引用**：搜索指令的图片路径填同一个变量名，就可以用刚抓下来的图去搜。
2. **覆盖**：勾选了固定名称时，重复抓图会覆盖同名文件。
3. **依赖 OpenCV**：本指令用 OpenCV 截图，插件不可用时会失败并提示。它和设置里的「截图方式」（微软 / RMT / SC）无关，那一项只给「RMT指令 · 截图」用。
4. **窗口抓图**：只截匹配到的第一个窗口，不会对多个窗口各截一张。

### ⌨️ 快捷键
1. **F1** / **左键框选截图范围**：框选后写入起始、终止坐标。

### 🧾 指令格式
- 本指令参数保存在配置里，宏中只写序列号。
- 格式：`抓图序号`，带备注时为 `抓图序号_备注`
- 示例：`抓图1`、`抓图1_当前血条`

## 38 注释

<!-- 指令分类：其他 -->

![注释配置界面](/RMT/Web/Images/MacroCMD/Comment.png)

### 📌 功能
1. **加说明**：在指令流里插入一段给人看的文字，方便以后阅读。
2. **只供阅读**：运行到本条时不执行动作、不改变量，直接继续下一条。

### ⚙️ 配置参数
1. **注释内容**：可写多行，不能只填空白。指令串只保留最长 20 个字符的摘要，超出时追加 `...`。编辑器和指令树会读取完整正文。

### 💡 特别说明

> 💡 **和指令备注**
> 其它指令序列号后面的备注，只是那一条的名字；注释是单独占一条位置的指令，专门用来写说明。

1. **不是跳过指令**：右键「跳过指令」会给某条可执行指令打上 `🚫`，那是暂时禁用它。注释本身就没有任何动作，不需要再跳过。

### 🧾 指令格式
- 格式：`注释序号_内容摘要`
- 示例：`注释1_下面开始吃药`
