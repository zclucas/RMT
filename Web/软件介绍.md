# 📘 词条介绍

本页用于介绍软件中各类名词与功能的含义说明。

---

## 🌐 全局操作

全局操作用于控制软件整体运行状态：

| 功能 | 说明 |
|------|------|
| 🌙 **休眠** | 立即终止所有宏，并禁用软件全部功能；取消休眠后恢复运行。 |
| ⏸️ **暂停** | 暂停当前所有宏，再次点击继续执行。 |
| ⛔ **终止所有宏** | 强制停止所有正在运行的宏任务，**不可恢复**，用于紧急情况。 |
| 🔄 **重载** | 重新加载当前配置，撤销未保存的修改（图形节点编辑器中的修改不会撤销）。 |
| 💾 **应用并保存** | 保存并立即应用所有修改；未点击前，修改的配置不会生效。 |

## 🗂️ 页签说明

软件主界面通过不同页签对功能进行分类管理：

| 页签 | 说明 |
|------|------|
| ⌨️ **按键宏** | 通过快捷键触发宏，支持手柄、键鼠以及它们的组合键（如 `Ctrl + C`）。 |
| 🔤 **字串宏** | 通过输入特定字符序列触发宏（如连续按键、输入字符串）。 |
| **手势宏** | 支持预设和自定义鼠标轨迹，也可映射 Windows 三指和四指触控板手势。 |
| 🧭 **菜单宏** | 通过快捷键呼出菜单轮盘，再由菜单按钮触发对应宏（可用 `F1`～`F8` 快捷触发）。 |
| 🪟 **界面宏** | 激活窗口时在界面上显示悬浮按钮，也可通过快捷键进行开关控制。自定义界面可以把控件绑定到某条宏的指定参数，运行中修改控件即修改该参数；可绑定的字段见「界面宏字段绑定支持表」。 |
| **语音宏** | 识别到指定的语音触发词后执行宏。 |
| ⏰ **定时宏** | 按时间触发宏，支持单次、软件启动时和周期触发，并可限制每次任务的运行时长。 |
| 🧩 **宏** | 可被其他宏调用的宏片段。 |
| 🎮 **按键替换** | 将某个按键映射为其他按键或组合键。 |
| **网络宏** | 收到配置的 HTTP 请求后执行宏。 |
| 🛠️ **工具** | 辅助功能集合，如变量监视器、文件校验、截图、录制、取色、窗口信息等。 |
| ⚙️ **设置** | 修改软件的全局配置与行为选项。 |
| ❓ **帮助** | 使用说明、开源地址、交流群、反馈与更新日志。 |
| ❤️ **赞助** | 支持作者持续维护与功能迭代。 |
| 🌟 **特别感谢** | 感谢代码贡献者、开源项目与社区成员。 |

## 📦 宏模块

对宏进行分类管理：

| 参数 | 说明 |
|------|------|
| 📝 **备注** | 对模块进行说明，便于后续管理与维护。 |
| 🪟 **前台** | 模块下所有配置只在设定的窗口中触发；置空则在所有窗口皆可触发。 |
| ➕ **新增宏** | 在模块最下方增加一条宏配置。 |
| 📋 **粘贴宏** | 需先点击宏配置中的「复制」，再点击「粘贴」，可将复制的宏内容添加到新增宏配置中。 |
| 📁 **新增模块** | 在当前模块下方新增一个模块。 |
| 🗑️ **删除模块** | 删除当前模块（不可恢复）。 |
| 🚫 **禁用（模块）** | 禁用当前模块下所有宏配置的手动触发（仍可通过宏操作调用触发）。 |
| 📋 **复制** | 复制当前宏内容，可在模块上粘贴使用。 |
| 🚫 **禁用（宏）** | 禁用当前宏配置，不参与触发与执行。 |
| 🗑️ **删除** | 删除当前宏配置（不可恢复）。 |
| ⌨️ **菜单触发键** | 配置当前模块菜单轮盘的触发按键。 |
| 🪟 **面板触发键** | 配置当前模块界面浮窗的控制开关。 |

## 🎯 宏配置

用于定义单条宏的触发方式与执行行为：

| 参数 | 说明 |
|------|------|
| 📝 **宏名称** | 对宏用途进行说明，便于管理与维护。 |
| ⌨️ **触发键编辑** | 打开触发键设置界面，进行可视化配置。 |
| 🖼️ **触发键编辑（菜单宏 / 界面宏）** | 打开扇区或界面按钮上的图标设置。 |
| ⏰ **触发键编辑（定时）** | 打开定时设置界面。 |
| 🎯 **触发类型** | 设置宏的触发按键与方式：<br>• **按下**：按下即触发，未松开可重复触发<br>• **松开**：松开时触发<br>• **松止**：按下持续触发，松开后终止<br>• **开关**：首次触发开始，再次触发终止<br>• **长按**：持续按下到指定时间后触发<br>• **双击**：双击触发键后触发 |
| 🔁 **循环次数** | 设置宏的重复执行次数（可下拉选择「无限」）。 |
| 🎹 **宏设置 · 按键类型** | • **AHK Send**：通用方式，适合办公软件与大多数游戏（管理员权限可让更多游戏有效）<br>• **keybd_event**：系统接口方式，适合老软件或游戏（需管理员权限）<br>• **罗技**：调用罗技驱动模拟按键（需管理员权限，并使用 G HUB 2022.2.1154 及以前版本）<br>• **AHI**：调用 Interception 驱动模拟按键（需管理员权限，并安装 Interception）<br>⚠️ *keybd_event、罗技和 AHI 的按键可作为宏的触发按键，切勿自己触发自己导致死循环* |
| 🔊 **宏设置 · 开始提示音** | • **无**：不播放提示音<br>• **触发提示**：触发时提示，循环触发会多次提示<br>• **循环首次提示**：触发时提示，循环触发不再提示 |
| 🔊 **宏设置 · 结束提示音** | • **无**：不播放提示音<br>• **结束提示**：宏结束时提示，循环多次结束就多次提示<br>• **循环结束提示**：结束时提示，循环结束不再多次提示 |
| ✏️ **宏指令编辑** | 打开宏指令编辑器，编辑宏内容。 |
| 📋 **复制** | 复制当前宏内容，可在模块上粘贴使用。 |
| 🚫 **禁用** | 禁用当前宏配置，不参与触发与执行。 |
| 🗑️ **删除** | 删除当前宏配置（不可恢复）。 |

## 📂 配置管理

对配置进行分类管理：

| 参数 | 说明 |
|------|------|
| 📥 **迁入配置文件夹** | 选择旧版本或同版本若梦兔（假定叫 A）的 `Setting` 文件夹，把 A 中所有配置覆盖同步到当前软件。<br>⚠️ *当前软件的所有配置会自动备份到 `SettingOld` 目录下* |
| ✏️ **重命名** | 修改当前配置名称。 |
| 🔧 **配置校准** | 迁入或重命名后若配置异常，可尝试使用该功能修复。 |
| ➕ **新增配置** | 新增一个配置。 |
| 📦 **导入配置** | 选择一个 `.rmt` 文件导入配置（共享仓库可下载）。 |
| 🔀 **合并导入** | 选择一个 `.rmt` 文件或本地已有的配置，合并到当前配置中。 |
| 📂 **加载配置** | 切换到选中的配置。 |
| 🗑️ **删除配置** | 删除选中的配置。 |
| 📄 **使用说明** | 共享仓库的配置要求必须填写；导入的 `.rmt` 文件配置可以查看说明。 |
| 📤 **导出配置** | 将选中的配置导出为 `.rmt` 文件，方便备份与分享。 |
| 🌐 **打开仓库** | 打开共享仓库，可以下载学习案例，或他人已经共享的游戏相关配置。 |

## 🛠️ 软件工具

文件校验、信息获取等辅助功能：

| 设置项 | 说明 |
|--------|------|
| 👁️ **变量监视器** | 可以实时查看全局变量的值，以便问题排查。 |
| ✅ **文件校验** | 为避免系统或人为误删除，可校验缺失资源并补齐。 |
| 🖱️ **鼠标信息** | 获取当前鼠标下详细信息：屏幕坐标、窗口坐标、窗口标题、进程名等等。 |
| 📌 **窗口置顶** | 软件主窗口置顶。 |
| ⏺️ **指令录制** | 录制手柄（需要额外配置）、键鼠操作，自动生成宏配置。 |
| 🔤 **图片文本提取** | 提取图片中的文字。 |

## ⚙️ 软件设置

用于调节整体行为与模拟真实性的全局参数：

| 设置项 | 说明 |
|--------|------|
| ⏱️ **点击时间浮动（%）** | 按键点击时间的浮动范围。例如：设为 10，原 50ms → 最终约 45～55ms。 |
| ⏳ **每次间隔浮动（%）** | 多次点击、多次搜索、多次提取间隔浮动范围。例如：设为 10，原 500ms → 实际约 450～550ms。 |
| ⌛ **间隔指令浮动（%）** | 间隔指令的浮动范围。例如：设为 10，原 3000ms → 实际约 2700～3300ms。 |
| ↔️ **坐标 X 浮动（px）** | 模拟点击时 X 坐标的浮动范围。例如：设为 30，原 X=900 → 实际约 870～930。 |
| ↕️ **坐标 Y 浮动（px）** | 模拟点击时 Y 坐标的浮动范围。例如：设为 50，原 Y=400 → 实际约 350～450。 |
| 🧵 **多线程数（-1～10）** | `-1`：动态多线程；`0`：单线程；`n`：多线程固定为 n。 |
| ⚡ **开机自启** | 开机时自动运行软件。 |
| 🛡️ **管理员启动** | 软件运行后提权为管理员。 |
| ⌨️ **自动松开修饰键** | 修饰键 + 普通键触发宏时，自动松开修饰键。 |
| 🔁 **连续触发** | 按下、开关、长按可以按住连续触发。（滚轮等无松开事件的按键不受此选项影响） |
| 💬 **无变量提醒** | 当使用不存在的变量时弹窗提示。 |
| 🪟 **模态子窗口** | 只有关闭子窗口才能操作主窗口。 |
| 🌐 **语言 / Lang** | 设置软件显示语言。 |
| 🔤 **软件字体** | 设置界面字体。 |
| 🧩 **首选编辑器** | 设置宏内容为空时打开的编辑器类型。 |
| 📸 **截图方式** | 设置截图实现方式；当截图报错时请切换其他截图方式。 |
| 🎮 **手柄类型** | 设置手柄宏的按键类型。 |
| ⌨️ **按下时按下** | 宏按键按下后再次按下时的特殊调整选项。 |
| 🎨 **主题** | 配置软件所有的颜色配比。 |
| ⌨️ **快捷键** | 修改软件所有的快捷按键。 |
| ⏺️ **指令录制** | 设置指令录制时的一些录制细节。 |
| 🎡 **轮盘** | 设置菜单轮盘大小、触发方式、显示位置。 |
| 🪟 **界面浮窗** | 设置界面宏的默认位置、大小等。 |
| 📺 **指令显示** | 设置宏执行时的内容显示位置等。 |
