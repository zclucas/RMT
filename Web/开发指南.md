# 📘 开发指南（RMT）

本文档概述了 RMT（若梦兔）按键宏工具的模块架构与功能，方便开发者快速理解项目结构与功能。

---

## 📂 项目总体架构

```
用户操作 / 热键触发
    ↓
BindUtil.ahk (热键路由)
    ↓
MacroUtil.ahk.OnTriggerMacroOnce (指令解析 & 分发)
    ↓
ExecuteMacroCmdOnce (单条指令执行)
    ├─ 键盘/鼠标/手柄模拟
    ├─ 图片识别 (OpenCV)
    ├─ 文字识别 (RapidOcr)
    ├─ 循环/条件判断
    ├─ 运行程序/脚本
    └─ 其他指令...
支持多线程: WorkPool.ahk → Thread/Work.exe (独立进程)
```

---

## 📂 主程序入口

### `RMT.ahk`
程序的主入口，负责初始化与启动。

**初始化流程：**
1. `SelfCheckMissingFiles()` — 文件完整性自检（开发阶段注释掉）
2. `InitFilePath()` — 初始化文件路径（配置文件、日志等）
3. `LoadCurMacroSetting()` — 加载用户配置文件
4. `HandleOpenArg()` — 处理打开软件的参数
5. `EditListen()` — 滚轮按键监听
6. `InitData()` — 初始化软件内部数据缓存
7. `InitUI()` — 初始化主界面 UI
8. `SetEditData()` — 缓存编辑器数据
9. `PluginInit()` — 初始化插件（耗时较长，放后面）
10. `TimingCheck()` — 轮询检测定时触发
11. `BindKey()` — 绑定全局快捷键

## 🧠 核心模块 (`Main/`)

### `GlobalUtil.ahk`
**功能概述：**
全局变量声明与模块引用中心。通过 `#Include` 串联所有核心模块和 GUI 模块。

**职责内容：**
- 声明 `MySoftData`、`MainSoftData` 等全局变量
- `#Include` 所有核心模块（WorkPool, UIUtil, TimingUtil, BindUtil, VariableUtil 等）
- `#Include` 所有 GUI 模块
- `#Include` 部分插件（ViGEm, AHK-XAML, MacroGraph）

---

### `DataClass.ahk`
**功能概述：**
定义程序中用到的数据结构与宏指令的数据模型。

**职责内容：**
- `TableItem` — 主表格数据结构，含每个宏项的状态、触发键、循环次数等
- `Timer` — 定时器/计划配置
- `SoftData` / `MainConfig` — 全局配置对象（主题、快捷键映射、用户偏好设置）
- 各类 `*Data` 类（`KeyboardData`, `SearchData`, `LoopData`, `RunData` 等）— 宏指令数据模型

---

### `AssetUtil.ahk`
**功能概述：**
统一管理资源（如图标、配置文件等）的加载、保存与转换。

**职责内容：**
- `InitFilePath()` — 初始化所有文件路径
- 加载本地资源（图像、图标、模板等）
- 保存用户生成的数据（宏配置文件）
- 语言文件加载与切换

---

### `SelfCheck.ahk`
**功能概述：**
文件完整性自检工具。

**职责内容：**
- `SelfCheckMissingFiles()` — 检查关键依赖文件是否存在（OCR模型、DLL、音频等）
- 若缺失则从 GitHub Releases 自动下载

### 工具模块 (`Main/Util/`)

#### `MacroUtil.ahk` — ⭐ 核心宏执行逻辑
**功能概述：**
解析并执行宏指令。

**职责内容：**
- `OnTriggerMacroOnce(tableItem, macro, index)` — 触发并执行单条宏（拆分指令、遍历执行）
- `ExecuteMacroCmdOnce(tableItem, cmdStr, index, graphNode)` — 执行单条宏指令
- 所有指令类型的执行函数：`OnPressKey`, `OnInterval`, `OnSearchWrapper`, `OnMouseMove`, `OnRunFile`, `OnCompare`, `OnVariable`, `OnLoop` 等
- 支持递归调用（循环、条件分支等）

#### `MacroClipboardUtil.ahk`
宏的复制、粘贴、导入导出操作。

#### `GraphMacroUtil.ahk`
流程图宏的执行逻辑。

#### `JsonUtil.ahk`
JSON 解析与序列化。

#### `InputUtil.ahk`
输入框验证与处理工具。

#### `TextOpsUtil.ahk`
文本处理指令的执行逻辑。

#### `SearchUtil.ahk`
图片搜索指令的执行逻辑（调用 OpenCV 插件）。

#### `CompareUtil.ahk`
条件比较指令的工具函数。

#### `ExcelUtil.ahk`
Excel 文件读写工具。

#### `FileIOUtil.ahk`
文件读写指令的执行逻辑。

#### `ExpressUtil.ahk`
表达式计算引擎。

#### `LangUtil.ahk`
国际化工具（加载语言文件、翻译字符串）。

#### `FixCompatUtil.ahk`
兼容性修复与旧版本数据迁移。

#### `Gdip_All.ahk`
GDI+ 图像处理库。

#### `HumanMouse.ahk`
人类化鼠标移动算法。

#### `PresssKeyUtil.ahk`
底层按键模拟工具。

### 其他核心模块

#### `WorkPool.ahk`
**功能概述：**
多线程 Worker 池管理。

**职责内容：**
- `TaskQueue` — 任务队列
- `WorkerData` — Worker 进程数据封装
- Worker 进程的创建、销毁、任务分发
- 通过共享内存 + 环形缓冲区与 Worker 通信

#### `BindUtil.ahk`
**功能概述：**
全局热键注册与触发路由。

**职责内容：**
- `BindKey()` — 绑定所有快捷键
- `BindShortcut()` — 注册单个热键/热字串
- `InitTriggerKeyMap()` — 初始化触发键映射
- 暂停/终止/截图/自由粘贴等工具热键

#### `UIUtil.ahk`
**功能概述：**
主窗口 UI 模板，负责构建和控制所有主窗口相关的 UI 元素。

#### `TimingUtil.ahk`
**功能概述：**
定时/计划宏的调度与执行。

**职责内容：**
- `TimingScheduler` — 定时调度器类
- 支持按时间、间隔、系统启动等多种触发方式

#### `VariableUtil.ahk`
**功能概述：**
变量管理与替换引擎。

**职责内容：**
- 系统变量与用户变量的读取/写入
- 宏文本中的变量替换
- 支持 `{变量名}` 语法

#### `RecordUtil.ahk`
**功能概述：**
键盘/鼠标宏录制。

**职责内容：**
- 底层原始输入（Raw Input）监听
- 按键/鼠标动作捕获与序列化

#### `RecordJoyUtil.ahk`
**功能概述：**
手柄宏录制。

#### `JoyMacro.ahk`
**功能概述：**
手柄宏支持（按键映射、轴处理）。

#### `TriggerKeyData.ahk`
**功能概述：**
触发键数据结构定义。

**职责内容：**
- `TriggerKeyData` 类 — 管理单个按键的多种触发方式（按下、松开、长按、双击、开关等）

#### `WindowHotkeyManager.ahk`
**功能概述：**
窗口热键管理器（为指定窗口绑定热键）。

#### `FolderPackager.ahk`
**功能概述：**
文件夹打包工具（用于导出配置）。

## 🆕 新指令添加流程（以"开源"指令 OpenSource 为例）

如果你想新增指令，请参考以下流程：

1. **新增数据保存文件路径**  
   在 `AssetUtil.ahk` 的 `InitFilePath` 函数中添加：  
   ```ahk
   global OpenSourceFile := A_WorkingDir "\Setting\OpenSourceSettings.ini"
   ```

2. **定义指令数据结构**  
   在 `DataClass.ahk` 中新增结构体 `OpenSourceData`，类似已有的 `RunData`。  
   重点字段：  
   - `SerialStr` — 指令序列化标识，必须唯一，用于区分不同指令。  
   - 其他参数根据指令需求定义。

3. **新增指令编辑界面**  
   - 复制现有的 `Gui/RunGui.ahk`，重命名为 `Gui/OpenSourceGui.ahk`。  
   - `GetCMDSerialStr("运行")` 改成 `GetCMDSerialStr("开源")`
   - 根据指令参数调整 `AddGui()` 和相关接口，确保界面能编辑对应参数。

4. **添加指令按钮入口**  
   - 在 `Gui/MacroEditGui.ahk` 中新增按钮，调用 `OpenSourceGui.ahk` 以打开编辑界面。  
   - 参考已有"文件"按钮实现。

5. **实现指令执行逻辑**  
   - 在 `Main/Util/MacroUtil.ahk` 的 `ExecuteMacroCmdOnce()` 中添加 `Actions` 映射：  
     ```ahk
     "开源", OnOpenSource,
     ```
   - 实现 `OnOpenSource()` 函数，复杂指令参考"按键"指令，简单指令参考"文件"指令。

## 🚀 Debug 运行测试

### 编译 Work.ahk
如果调整会对 `Work.ahk` 有影响，需要先重新编译：
如果重新编译觉得麻烦，也可以临时把多线程改成 0。

1. **清理旧文件**  
   删除 `Thread` 目录下所有的 `.exe` 文件（或删除后运行时会自动重新生成）。

2. **打开编译工具**  
   通过 `AutoHotkey Dash` → 选择 `Compile`。

3. **选择源文件**  
   - **Source**：选择 `Thread\Work.ahk` 文件。

4. **设置输出路径**  
   - **Destination**：设置为 `Thread` 目录下的 `Work.exe`。

### 运行 RMT.ahk
直接双击 `RMT.ahk` 文件即可运行。
