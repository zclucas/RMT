# 💻 命令行

其他软件可以用 `rmt` 命令控制正在运行的若梦兔：启动或停止宏、暂停与继续、读写变量、查询运行状态。

---

## 📌 使用说明

先正常打开一次若梦兔。软件会把程序路径写入环境变量 `rmt`，并把 `rmt` 命令加入当前用户的 PATH。之后**重新打开终端**，在任意目录都可以直接输入命令。

| 项目 | 说明 |
|------|------|
| 🔤 **环境变量 `rmt`** | 程序完整路径。编译版是 exe，源码运行时是启动脚本。 |
| 🖥️ **命令 `rmt`** | 新开的终端里直接使用，不必先进入软件目录。 |
| 🔢 **位置 `m-n`** | 第 `m` 个页签里的第 `n` 个宏，从 **1** 开始。例如 `1-2` 是第 1 页第 2 条宏。 |
| ✅ **退出码 `0`** | 执行成功。查询类命令的结果写在标准输出。 |
| ❌ **退出码 `1`** | 参数不对，或页签、宏、变量、数组不存在。原因写在标准输出。 |
| ⏱️ **退出码 `2`** | 若梦兔没能及时启动，或指令等待超时。 |

> 若梦兔已经打开时，命令交给当前实例执行，不会把正在运行的宏关掉。若梦兔没打开时，命令会先把软件拉起来，再执行。

> 管理员身份运行编译版时，同名变量还会写入系统环境变量。

值里含有空格时请加引号：

```bat
rmt -set 标题 "第一行 内容"
```

---

## ❓ 帮助

显示全部命令及其作用。

```bat
rmt -help
```

| 项目 | 说明 |
|------|------|
| 📤 **输出** | 命令列表，写在标准输出。 |
| 💡 **适合** | 忘记写法时先看这一条，或让其他软件读取帮助文本。 |

---

## 🌙 后台运行

静默打开若梦兔，不显示主界面，软件留在托盘里继续工作。

```bat
rmt -min
```

| 项目 | 说明 |
|------|------|
| 🪟 **界面** | 不打开主窗口。 |
| 🔗 **连用** | 可以和其他命令一起写，例如 `rmt -min -run 1-2`：后台打开，并启动第 1 页第 2 条宏。 |

> 若梦兔已经在前台打开时，再执行 `rmt -min` 会把主界面收起。

---

## ▶️ 启动指定宏

运行第 `m` 个页签下的第 `n` 个宏。

```bat
rmt -run 1-2
```

| 项目 | 说明 |
|------|------|
| 📍 **参数** | `m-n`。`1-2` 表示第 1 个页签的第 2 条宏。 |
| ✅ **成功** | 退出码 `0`。宏开始执行，不需要等待宏自己跑完。 |
| 🚫 **禁用** | 这条宏或它所在模块被禁用时，不会启动，并返回「该宏已禁用」。 |

---

## ⛔ 终止指定宏

终止第 `m` 个页签下的第 `n` 个宏。

```bat
rmt -kill 1-2
```

| 项目 | 说明 |
|------|------|
| 📍 **参数** | `m-n`，与 `rmt -run` 使用同一套序号。 |
| 🛑 **效果** | 停止这一条宏。正在运行时会按终止处理。 |

---

## 🛑 终止所有宏

终止所有页签下正在运行的宏。

```bat
rmt -killall
```

| 项目 | 说明 |
|------|------|
| 📦 **范围** | 每一个页签里正在运行的宏。 |
| ⚠️ **注意** | 这是全部停止，不是停止某一条。停止某一条请用 `rmt -kill m-n`。 |

---

## ⏸️ 暂停指定宏

暂停第 `m` 个页签下的第 `n` 个宏。

```bat
rmt -pause 1-2
```

| 项目 | 说明 |
|------|------|
| 📍 **参数** | `m-n`。 |
| 🟡 **状态** | 暂停后，`rmt -status m-n` 返回 `2`。 |

---

## ⏯️ 继续指定宏

取消暂停，让第 `m` 个页签下的第 `n` 个宏继续执行。

```bat
rmt -resume 1-2
```

| 项目 | 说明 |
|------|------|
| 📍 **参数** | `m-n`，对应之前暂停的那一条。 |
| 🟢 **状态** | 正在运行的宏继续后，`rmt -status m-n` 返回 `1`。 |

---

## 🧊 暂停所有宏

暂停所有页签下的所有宏。

```bat
rmt -pauseall
```

| 项目 | 说明 |
|------|------|
| 📦 **范围** | 全部页签、全部宏。 |
| 🔁 **恢复** | 用 `rmt -resumeall` 一起继续，或用 `rmt -resume m-n` 继续其中一条。 |

---

## 🔁 继续所有宏

取消全部暂停，让所有页签下的宏继续。

```bat
rmt -resumeall
```

| 项目 | 说明 |
|------|------|
| 📦 **范围** | 全部页签、全部宏。 |
| ▶️ **对应** | 与 `rmt -pauseall` 成对使用。 |

---

## ✏️ 设置变量

给若梦兔的全局变量写入一个值。没有这个变量时直接新增。值一律按字符串保存。

```bat
rmt -set 次数 3
rmt -set 标题 "今日副本"
```

| 项目 | 说明 |
|------|------|
| 🏷️ **key** | 变量名。 |
| 📝 **value** | 变量值，类型是字符串。已有同名变量时覆盖原值。 |
| 👀 **可见** | 正在运行的宏和变量监视器会看到这个新值。 |

---

## 📖 获取变量

读取若梦兔的全局变量。结果统一是字符串。

```bat
rmt -get 次数
```

| 项目 | 说明 |
|------|------|
| 📤 **输出** | 变量当前的文本，例如 `3`。 |
| ❌ **不存在** | 退出码 `1`，并提示变量不存在。空字符串是合法的值，请同时看退出码。 |

---

## 📚 设置数组

给若梦兔的数组变量写入一串值。没有这个数组时直接新增。

```bat
rmt -setarr 名单 [1,2,3,4]
```

| 项目 | 说明 |
|------|------|
| 🏷️ **key** | 数组名。 |
| 🧩 **value** | 用方括号包住，元素用英文逗号分隔，例如 `[1,2,3,4]`。 |
| 🔤 **元素** | 元素按字符串保存。`[1, 2, 3]` 里的空格会被去掉。 |

> 嵌套数组同样使用方括号，例如 `rmt -setarr 分组 [1,[2,3],4]`。

---

## 🔍 获取数组

读取若梦兔的数组，结果统一是字符串。

```bat
rmt -getarr 名单
```

数组内容是 `1,2,3,4` 时，标准输出为：

```text
[1,2,3,4]
```

| 项目 | 说明 |
|------|------|
| 📤 **输出** | 带方括号的文本。空数组返回 `[]`。 |
| ❌ **不存在** | 退出码 `1`，并提示数组不存在。 |

---

## 📊 查询状态

查询第 `m` 个页签下第 `n` 个宏现在的运行状态。

```bat
rmt -status 1-2
```

| 返回值 | 含义 |
|--------|------|
| `0` | 闲置，当前没有在跑。 |
| `1` | 正在运行。 |
| `2` | 暂停中。 |

> 其他软件读取标准输出中的这一个数字即可，成功时退出码为 `0`。页签或宏不存在时退出码为 `1`。
