WebViewToo 帮助

WebViewToo 是面向 AutoHotkey v2 的 WebView2 封装库。它让 AHK 程序可以使用本地 HTML、CSS 和 JavaScript 构建界面，同时继续由 AHK 负责窗口、文件、热键和运行时逻辑。

RMT 当前使用 WebViewToo 驱动主界面，只应加载 WebViewToo 自带的 WebView2 封装，不能再同时加载旧的 `Plugins\WebView2\WebView2.ahk`。

主要类

  • WebViewGui：直接创建一个 WebView 窗口，适合完整 Web UI。
  • WebViewCtrl：把 WebView2 控件嵌入普通 AHK `Gui`。
  • WebViewSizer：为无标题栏窗口提供缩放手柄，通常由 `WebViewGui` 内部使用。

路由与资源

WebViewToo 可以把本地目录、单个文件或文本内容映射到 WebView 页面可访问的地址。

MyGui.BrowseFolder(A_WorkingDir)
MyGui.Navigate("WebViewApp/dist/index.html")

RMT 使用这种方式加载 `WebViewApp\dist\index.html`，因此前端改动后必须重新构建 `WebViewApp\dist`。

AHK 与 JS 交互

AHK 可以向页面暴露回调，页面通过 JSON 调用 AHK，再由 AHK 返回新的状态。

MyGui.AddCallbackToScript("RmtAction", RmtWebAction)

RMT 的桥接入口在 `Main\UIUtil.ahk`，前端类型定义在 `WebViewApp\src\types.ts`。

RMT 集成

  • 主入口：`RMT.ahk` 调用 `InitUI()` 初始化 WebView 界面。
  • AHK 桥接：`Main\UIUtil.ahk`。
  • 前端源码：`WebViewApp\src`。
  • 前端构建产物：`WebViewApp\dist`。
  • WebView2 loader：`Plugins\WebViewToo\Lib\32bit` 和 `Plugins\WebViewToo\Lib\64bit`。

常见报错

`class WebView2 conflicts with an existing Class`

原因是同时 include 了两份 WebView2 封装。保留 WebViewToo，移除旧 `Plugins\WebView2\WebView2.ahk` include。

WebView 页面空白

检查 `WebViewApp\dist\index.html`、`WebViewApp\dist\assets`、WebView2 loader DLL 和 Microsoft Edge WebView2 Runtime 是否存在。

修改前端后没有变化

进入 `WebViewApp` 执行：

npm.cmd run build
