Tesseract OCR runtime for RMT

Native DLLs: Tesseract 5.2.0 and Leptonica 1.82.0, x86 and x64,
from Charles Weld's Tesseract 5.2.0 NuGet package:
https://www.nuget.org/packages/Tesseract/5.2.0
https://github.com/charlesw/tesseract
https://github.com/tesseract-ocr/tesseract/tree/5.2.0
https://github.com/DanBloomberg/leptonica/tree/1.82.0
Only the native runtime DLLs are used; no .NET wrapper is required.
Requires Microsoft Visual C++ 2015-2022 runtime for the matching architecture.

Language models: chi_sim.traineddata and eng.traineddata from tessdata_fast.
https://github.com/tesseract-ocr/tessdata_fast
These integer LSTM models require OEM 1. RapidOCR ONNX models and character
lists are not compatible with Tesseract traineddata.
